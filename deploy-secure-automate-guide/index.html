Deploy, Secure & Automate Full-Stack Web Apps

Take a full-stack app — a FastAPI backend, a Vue.js front end and a Meilisearch search engine — from code on your laptop to a secure, automated production server on an Ubuntu droplet. You do everything by hand first, so you truly understand it, then automate the whole release with a CI/CD pipeline. Six modules, nineteen lessons, every command and config explained for people deploying for the very first time.

▶ Watch the full video

How this guide is organised

The course is six modules, read in order. Each builds on the server you hardened in the one before.

By the end, this is the system you will have running in production:

Stack

LayerToolUsed for
HostingDigitalOcean dropletRent an Ubuntu virtual server reachable from the public internet.
Operating systemUbuntu 24.04The Linux OS you harden and run everything on.
AccessSSH (ed25519 keys)Log in to the server securely with keys instead of passwords.
FirewallUFW + Fail2BanAllow only chosen ports; auto-ban brute-force and abusive IPs.
BackendPython / FastAPIThe application code that serves the API.
App serverGunicorn + SupervisorRun FastAPI with worker processes and keep it alive.
Web serverNginxReverse proxy to the app, serve the Vue build, add security headers.
SearchMeilisearchSelf-hosted search engine behind the API.
CertificatesLet's Encrypt (certbot)Free, auto-renewing HTTPS/TLS certificates.
CDNCloudflareCache static assets at the edge, hide the origin, enforce full TLS.
CI/CDGitHub ActionsAutomate tests, security scans and deployment.
Security scanningBandit / OWASP ZAPStatic analysis on code and dynamic (DAST) scans on the live site.
MonitoringGoAccess / btop / LocustRead traffic logs, watch resources, and load-test the server.
