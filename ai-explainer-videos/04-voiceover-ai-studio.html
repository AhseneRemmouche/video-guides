Generate the voice-over in Google AI Studio

Using Gemini Flash TTS: create a dialog, choose a voice, paste the voice description and the expressive script, then download the audio.

▶ Watch this part (00:03:34)

You have a script with a voice description and a per-line expression. Now you turn those words into actual spoken audio. You leave Claude for a moment and visit a second website, Google AI Studio, whose text-to-speech tool reads your script aloud. The video walks through this at 3:34.

The output of this step is one audio file: your finished voice-over. You will carry it back to Claude in the next step. Nothing here needs code - it is all done by clicking and pasting in the browser.

Where you are going

Open aistudio.google.com in your browser. Inside Google AI Studio there is a tool for generating speech - the video calls it the Generate Speech tool. The model shown doing the reading is Gemini 3.8 Flash TTS, part of Google's Gemini family. This tool is special because it accepts two things your script already has: a description of how the voice should sound, and an expression for each line.

Doing it, click by click

Follow these in order. The exact wording of buttons and panels can change over time, so match the idea if a label differs.

  1. Go to aistudio.google.com and open the Generate Speech (text-to-speech) tool. Confirm the model is Gemini 3.8 Flash TTS.
  2. Click Create new dialog to start a fresh speech project.
  3. In the speaker settings, pick a voice. There are many to choose from, sorted by things like language, male or female, pitch, and use case. The video picks a storyteller-style voice named Enzo, which suits a children's explainer.
  4. Find the Style field and paste Claude's voice description into it. This steers the overall character of the read.
  5. Paste the script with its per-line expressions into the main script box. The expressions tell the tool the feeling for each line.
  6. Press Run. The audio plays as it is generated, so you can listen right away.
  7. When you are happy with it, click Download to save the audio file. The video gives it a clear name, such as airplanes explainer voiceover, so it is easy to find later.
New to this? Why there are two separate inputs

The voice description and the expression cues do different jobs. The description is the whole-performance setting - it goes in the Style field and colours every line the same way (a warm storyteller, say). The expressions live inside the script, one per line, and change the feeling sentence by sentence. Putting the description in Style and leaving the expressions in the script is what keeps the two working together.

Why does the video rename the download?

You will often make several voice-overs - different topics, or a kids' version and an adults' version of the same topic. A clear file name like "airplanes explainer voiceover" means that when you go back to Claude and attach the file, you pick the right one. It is a small habit that saves confusion later.

Listen before you download

Because the audio plays as it generates when you press Run, you get to judge it immediately. If the pacing is off, a line sounds wrong, or the mood does not fit, you can adjust and run again before downloading. It is worth getting this right here, since the whole video will be timed to this audio.
