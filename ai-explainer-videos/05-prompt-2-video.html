Prompt 2: turn the voice-over into a motion-graphics video

Attaching the voice-over and asking Claude to generate a motion-graphics video matched to its timing, with no captions.

▶ Watch this part (00:06:23)

You now have two things: the script Claude wrote in step 3, and the spoken voice-over audio file you downloaded from Google AI Studio in step 4. This step joins them back together. You hand the audio back to Claude and give it a second, short prompt that asks for an animated motion-graphics video timed to that narration. That one message is the whole step.

It feels almost too simple. In the video (at 06:23) the creator just drops the audio file into the same chat, pastes one prompt, and sends it. There is no timeline to edit and no video software to learn. The clever part is already written for you in the prompt below, so most of this page is about understanding what each sentence of that prompt is asking Claude to do.

What is happening in this step

The first prompt turned an idea into words. The text-to-speech tool turned those words into a voice. This second prompt asks Claude to turn that voice into pictures that move in step with it. Because you are still in the same Co-work chat from the earlier steps, Claude already has the script in its memory; attaching the audio gives it the exact timing of every spoken line.

One instruction in the prompt is easy to miss but important: it tells Claude not to add captions or subtitles. We will come back to why that matters.

Do it

  1. Open the same chat. Go back to the Co-work chat in Claude where the script was written. Staying in the same chat means Claude still has the script and the earlier context.
  2. Attach the voice-over file. Either drag the downloaded audio file from your computer straight onto the message box, or click the + button next to the box and choose Add files, then pick the audio. Wait until the file appears as an attachment on your unsent message.
  3. Paste Prompt 2. Copy the prompt below exactly and paste it into the message box, on the same message as the attached audio.
  4. Send it. Press send. Claude will begin uploading and working. What happens next (the wait, the summary, and the download) is step 6.

Prompt 2, word for word

This is the creator's own second prompt, copied exactly. Unlike the first prompt, it has no blanks to fill in: send it as it is.

attached is the voiceover. Generate the motion graphics video to match the voice over timing perfectly, go all out and impress me. do not generate captions or subtitles.

What each sentence asks for

Part of the promptWhat it tells Claude
attached is the voiceover.Points Claude at the audio file on the message. This is the source of the exact timing: where each sentence starts and ends.
Generate the motion graphics video to match the voice over timing perfectlyAsks for animation whose on-screen moments line up with the spoken words, so a picture appears when its sentence is heard. This is the whole point of handing back the real audio instead of just the text.
go all out and impress me.Encourages richer, more polished visuals rather than something plain. It is a style nudge, not a technical setting.
do not generate captions or subtitles.Tells Claude to leave words off the screen. The narration already carries the message, and on-screen text would compete with it. This keeps the result a clean motion-graphics piece.
New to attaching files in a chat? What it means here

Attaching a file adds it to the message you are about to send, the way you would attach a photo to an email. The model can then read or listen to that file as part of your request. Here the attachment is the audio you made in step 4. Claude listens to it to learn the exact moment each line is spoken, which is how the finished animation can be timed to the narration. If you send the prompt without the file attached, Claude has no audio to match and cannot do the step.

Why “match the timing” needs the audio, not just the script

The script is only words on a page; it does not say how long each line takes to say, or how much silence sits between lines. The spoken voice-over does. By attaching the real audio, you give Claude the one thing the text cannot provide: a clock. That is why this step hands the audio back instead of asking Claude to guess timings from the script alone.

Why ask for no captions?

Captions (also called subtitles) are the words printed on screen that repeat what is being said. They are helpful for silent viewing or accessibility, but in a short narrated explainer they can clutter the picture and pull the eye away from the animation. The creator chose a clean look, so the prompt explicitly asks for none. If you later decide you want captions, that is a different choice you would ask for on purpose.

What you should see. Before you send, your message box should show two things together: the attached audio file (with its name and a small icon) and the pasted text of Prompt 2. Once you send, Claude starts working on that same message. You have not downloaded anything yet; that comes in the next step.
Common mistakes.
  • Forgetting the attachment. If you paste the prompt but do not attach the audio, the first sentence (“attached is the voiceover”) points at nothing. Always confirm the file chip is on the message first.
  • Starting a brand-new chat. If you open a fresh chat, Claude no longer has the script context from earlier. Reuse the same Co-work chat.
  • Editing the prompt by accident. It is tempting to “improve” the wording. Send it as written the first time; you can always ask for changes afterwards (step 6).
  • Attaching the wrong file. Make sure it is the voice-over audio you downloaded, not the script text or some other file.
Recap
  • Reopen the same Co-work chat, attach the downloaded voice-over, paste Prompt 2, and send.
  • Prompt 2 is fixed text with no blanks; the audio attachment supplies the timing Claude animates to.
  • The prompt asks for visuals that match the narration, a richer style, and no captions or subtitles.
  • Getting the video, the wait, and iterating on it are the next step.
