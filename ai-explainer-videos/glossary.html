Glossary

Every technical term in this guide, explained for beginners.

Every technical term used in this guide, in plain language, grouped by topic. Each page links here the first time it uses a term.

The AI workflow

Large language model (LLM)
An AI trained on huge amounts of text (and sometimes images, audio and files) that responds to instructions written in plain language. Claude and Gemini are large language models.
Claude
Anthropic's AI assistant. In this workflow it writes the voice-over script and produces the animated video.
Opus
The most capable family of Claude models. The video uses Opus 5.5 for its quality on creative, multi-step work.
Sonnet
A Claude model tier that balances speed and capability, usually faster and cheaper than Opus. The video mentions Sonnet 5.5 as an alternative.
Effort
A setting that tells Claude how hard to think before answering. Higher effort can improve hard tasks but takes longer; the video found medium effort was the best trade-off here.
Co-work mode
A Claude mode for working alongside the model on a task over several steps, rather than a plain back-and-forth chat. The video uses it to produce the video file.
Prompt
The instruction you give an AI. This workflow uses two prompts: one to write the script, one to make the video.
Non-determinism
The property that the same prompt can produce different results each time, because the model samples its output. Expect variation, and run again if you want another take.
Text-to-speech (TTS)
Software that turns written text into spoken audio. Google AI Studio's Gemini Flash TTS is the one used here.
Google AI Studio
Google's web app for trying its AI models, including a Generate Speech tool that voices text with Gemini.
Gemini
Google's family of AI models. The video uses Gemini Flash TTS to generate the voice-over.
Voice description
A short written description of how a voice should sound (age, tone, mood). You paste it into the TTS tool's Style field to steer the read.
Expression
A per-line note telling the TTS tool the emotion or delivery for that line, so the narration is not flat.
Voice-over
The spoken narration track. Here it is generated first, then the animation is built to match its timing.
Motion graphics
Animated graphic design: shapes, text and illustrations that move. Explainer videos are usually motion graphics rather than filmed footage.
Explainer video
A short video that explains one idea clearly, usually with a voice-over and simple animation.
Captions
On-screen text of the narration (subtitles). The video's Prompt 2 asks for none.

Video and rendering

Frame
One still image in a video. Play many frames per second in order and the eye sees motion.
Frames per second (fps)
How many frames are shown each second. This guide uses 30 fps, so a 37-second video is about 1119 frames.
Timeline
The mapping of time to what appears on screen. Ours lists when each narration line starts and ends so the animation can line up with it.
Easing
Smoothing a change so it starts and stops gently instead of moving at a constant, robotic speed.
Interpolation
Working out in-between values over time, for example moving a shape from x=100 to x=1160 across a range of frames. Remotion's interpolate does this.
Codec
The method used to compress video or audio so the file is small enough to share. H.264 (video) and AAC (audio) are common ones.
MP4
A common video file format (container) that holds compressed video and audio together. Our renders are MP4 files.
AAC
A widely supported audio codec. Our voice-over ends up as AAC inside the MP4.
H.264
A very widely supported video codec, the default for MP4 output here.
Render
To turn a source (code, a scene, a timeline) into finished frames and then a video file. "Rendering" is doing that work.
Headless browser
A real browser running without a visible window. Remotion uses one to draw each frame; a plain Chrome in this mode is how we captured screenshots.
Audio sync
Lining the picture up with the sound, so an action happens exactly when the narration mentions it.
Aspect ratio
The width-to-height shape of the video, such as 16:9 (wide) or 9:16 (vertical for phones).
Resolution
How many pixels wide and tall the video is, such as 1280 by 720.
WebGL
The browser technology that draws hardware-accelerated 3D graphics. Three.js is built on it.

Remotion

Remotion
A library for making videos with React code. You write components; Remotion renders them to an MP4, one frame at a time.
Composition
One video defined in Remotion: a component plus its width, height, fps and duration. A project can hold several.
useCurrentFrame
A Remotion hook that tells your component which frame is being drawn, so the picture can depend on time.
Sequence
A Remotion wrapper that shifts and limits when its children appear on the timeline, used to arrange scenes.
Audio component
Remotion's <Audio>, which adds a sound track to a composition so it is included in the render.
staticFile
A Remotion helper that references a file in the project's public/ folder, such as the voice-over.
Props
Inputs passed into a component. In Remotion you can pass props to a composition to change the video without editing code.
durationInFrames
How many frames long a composition is. Ours is 1119, which is 37.295 seconds at 30 fps.

Three.js

Three.js
A popular JavaScript library for 3D graphics in the browser, built on WebGL.
Scene
The 3D world container that holds everything you want to draw - objects, lights and a background.
Camera
The virtual viewpoint the scene is drawn from. Its position and field of view decide what you see.
Mesh
A 3D object: a shape (geometry) combined with a surface (material).
Geometry
The shape of a mesh, such as a box, sphere, cylinder or cone.
Material
How a mesh's surface looks - its colour and how it responds to light.
Light
A source that illuminates the scene so materials are visible and shaded, such as an ambient fill or a directional "sun".
Renderer
The Three.js object that draws the scene from the camera onto the canvas using WebGL.
Scene graph
The tree of objects in a scene. Grouping objects lets you move or rotate them together.
react-three-fiber
A library that lets you describe a Three.js scene with React components instead of imperative calls. @remotion/three builds on it.
@remotion/three
Remotion's integration that renders a react-three-fiber canvas deterministically per frame, so 3D records cleanly to video.
Vector
A set of numbers describing a position or direction in space, such as [x, y, z] for where an object sits.
Primitive
A basic built-in shape (box, sphere, cylinder, cone). Our airplane is made entirely from primitives, with no model files.

Web and tooling basics

React
A popular library for building user interfaces from components. Remotion videos are written as React components.
Component
A reusable piece of UI (or, in Remotion, of a video) written as a function that returns what to show.
JSX
The HTML-like syntax used inside React code to describe what to render.
Node.js
A way to run JavaScript outside the browser - on your computer or a server. Remotion's command-line tool runs on Node.
npm
Node's package manager, used to install libraries like Remotion and Three.js into a project.
CDN
A content delivery network: fast public servers that host files such as libraries, so a page can load them by URL.
SVG
Scalable Vector Graphics - shapes and text described by code, which stay sharp at any size. Our 2D explainer is drawn in SVG.
Import map
A small piece of HTML that tells the browser where to fetch a named module from, so you can write import ... from "three" with no build step.
FFmpeg
A powerful command-line tool for processing audio and video. Remotion uses it under the hood to encode the final file.
DOM
The live tree of elements a browser builds from a page, which code can read and change.
