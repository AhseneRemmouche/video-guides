Prompt 1: write the voice-over script

The first prompt: ask Claude for a TTS script with a voice description and a per-line expression, filling in audience and topic.

▶ Watch this part (00:01:37)

Now you write the first of the two prompts. Its job is to get Claude to produce the narration script - the words a voice will later read aloud. The video introduces this prompt at 1:37, and it comes straight from the creator's own notes. We show it below exactly as written so you can copy it.

This is the most important text in the whole workflow, because a small instruction here shapes everything downstream: the script, the voice, and the final video. We will look at it as a whole first, then take it apart phrase by phrase.

Prompt 1, word for word

Here is the prompt exactly as the creator uses it. Copy it as is, then change only the two bracketed parts, [audience] and [topic].

write a script in egyptian arabic, that i will use to give to a tts tool, to generate a voice, that i will then feed back to you, to generate a motion graphics explainer for [audience], about [topic], i will use google 3.8 flash tts, it allows me to add a description for the voice and add expressions for each line in the script, so take that into consideration

Notice there is no capitalisation or tidy punctuation. That is fine - Claude understands it anyway, and we keep it unchanged so it matches what the video shows. The power is not in the grammar; it is in what the sentence tells Claude to plan for.

Reading the prompt phrase by phrase

Each part of this one long sentence is doing a job. Here is what each phrase asks for and why it matters.

Filling the two blanks

You only ever change [audience] and [topic]. Replace the brackets and the word inside with your own text. The video's example (at 1:37) uses a child audience and the airplanes topic.

  1. Replace [audience] with who the video is for. The video's example: a 7 years old child. Other examples: adults, university students, complete beginners.
  2. Replace [topic] with the subject. The video's example: how airplanes fly. Swap in any subject you want to explain.
  3. Leave the rest of the sentence exactly as written. Paste it into Claude (in Co-work mode, from the previous step) and send.

Here is the prompt with the video's example values filled in, so you can see what a completed version looks like:

write a script in egyptian arabic, that i will use to give to a tts tool, to generate a voice, that i will then feed back to you, to generate a motion graphics explainer for a 7 years old child, about how airplanes fly, i will use google 3.8 flash tts, it allows me to add a description for the voice and add expressions for each line in the script, so take that into consideration
New to "text-to-speech"? What the prompt means by a "tts tool"

Text-to-speech (TTS) is software that turns written words into spoken audio. The prompt tells Claude that the script is bound for a TTS tool, so Claude writes lines that sound natural when spoken, rather than dense text that only reads well on paper. In the next step you will use Google AI Studio's TTS tool to actually voice this script.

Can I write the prompt in English instead of Arabic?

Yes. The video explains (around this part) that you can write the instruction in Arabic or in English, and that English is often easier and faster. The phrase write a script in egyptian arabic controls the language of the script Claude produces, not the language you type the instruction in. To get a script in another language, change that phrase - for example, write a script in english.

What Claude gives you back

Because the prompt told Claude about the voice tool's features, Claude does not just return plain sentences. It returns two extra things that the next step needs:

  • A voice description: a short note on how the narrator should sound - for example a warm, playful storyteller for a child audience. You will paste this into the voice tool's Style field later.
  • An expression for each line: a small cue such as "curious" or "excited" attached to that line, so the voice-over is lively instead of flat.
New to "voice description" and "expression"? How they differ

A voice description sets the overall character of the narrator once - age, tone, mood - and applies to the whole reading. An expression is per line: it tells the tool the feeling for that single sentence, so one line can be curious and the next excited. Together they turn a flat robotic read into something that sounds like a real storyteller.

What you should see. A reply from Claude containing a short voice description and a narration script in your chosen language, where each line carries an expression cue. That is everything the next step needs.
Common mistakes. Editing more of the prompt than the two blanks - leave the rest word for word. Deleting the part about expressions and the voice description, which is exactly what makes Claude return those useful extras. Forgetting to replace both [audience] and [topic], so Claude asks you to clarify. Remember too that Claude is non-deterministic: send the same prompt twice and the script will differ. If you do not like a take, simply ask again.
