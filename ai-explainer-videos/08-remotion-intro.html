Why code your videos? Remotion in five minutes

Remotion makes videos from React: compositions, frames, fps and useCurrentFrame. Why coding the video makes it reproducible.

Extension - our own code, rendered to a real MP4

In Part 1 you let Claude make the whole explainer for you inside Co-work mode. That is fast and it works. But the video never shows how Claude turns the voice-over into a moving picture, and you cannot open the result and change one number. This part of the guide takes the other road: you build the same kind of explainer yourself, in code, where every frame is something you wrote and can re-run exactly. It is an extension beyond the video, offered as one concrete, reproducible recipe for the same idea.

The tool we use is Remotion. The one-line idea: you write a normal React component, and Remotion turns it into an MP4 video file. That is the whole trick. If you have ever built a web page with React, you already know most of what you need.

The big idea: React drawings, played back as video

A video is just a stack of still pictures shown quickly, one after another. Each still picture is a frame. The speed is measured in frames per second, or fps. Our project runs at 30 fps, so one second of finished video is 30 separate pictures.

Remotion gives your component one tiny piece of information through a hook called useCurrentFrame: "which frame am I drawing right now?" Your job is to answer "here is what the picture looks like on that frame." Remotion calls your component once for frame 0, once for frame 1, once for frame 2, and so on, collects every picture it gets back, and stitches them into a video. You never write a loop and you never touch the video file by hand.

New to React? What it is and why it matters

React is a popular library for building user interfaces out of small, reusable pieces called components. A component is a function that returns a description of what to show. In a web app, React keeps the page in sync with your data. Remotion reuses the same idea, but instead of a live web page the output is a video. If React is new to you, think of a component as "a function that returns a picture."

New to Node and npm? What they are

Node is a program that runs JavaScript on your computer instead of in a browser. npm is the tool that comes with Node for downloading libraries (other people's code) and running project scripts. When you type npm install, npm reads your project's package.json, downloads every library listed there, and drops them into a folder named node_modules. We locked Node to v24.15.0 and npm to 12.1.0 for this project.

Set up the project

You only do this once. Each line below is a plain terminal command or a file to create.

  1. Install Node (we used v24.15.0). This also gives you npm and the npx runner.
  2. Make an empty folder for the project, for example explainer-videos, and open a terminal inside it.
  3. Create the file package.json shown below. It names the project and, more importantly, lists the exact library versions.
  4. Run npm install. npm reads package.json and downloads Remotion, React, Three.js and the type packages into node_modules.
  5. Create the two small files src/index.ts and src/Root.tsx (both below). They tell Remotion where your videos are.
  6. Run npm run preview to open Remotion Studio, a live preview in your browser where you can scrub through the video while you work.

New to JSX and .tsx files? A quick word

JSX is the HTML-looking syntax React lets you write inside JavaScript, like <Composition />. A file that contains JSX is named with a .tsx extension (TypeScript plus JSX); a file with no JSX, like index.ts, uses plain .ts. That is the only reason the two files have different endings.

Now the root itself. Root.tsx is a list: it registers each video (each composition) with its size and length.

import React from "react";
import { Composition } from "remotion";
import { Explainer2D } from "./Explainer2D";
import { ThreeExplainer } from "./ThreeExplainer";
import { TIMELINE } from "./scenes2d";

// durationInFrames must cover the whole voice-over (37.295s at 30fps = 1119 frames).
const DURATION = Math.ceil(TIMELINE.durationSec * TIMELINE.fps);

export const RemotionRoot: React.FC = () => {
  return (
    <>
      <Composition
        id="Explainer2D"
        component={Explainer2D}
        durationInFrames={DURATION}
        fps={TIMELINE.fps}
        width={1280}
        height={720}
      />
      <Composition
        id="Explainer3D"
        component={ThreeExplainer}
        durationInFrames={DURATION}
        fps={TIMELINE.fps}
        width={1280}
        height={720}
      />
    </>
  );
};

What is a composition exactly?

In Remotion, a composition is one named video recipe. It bundles four things: a unique id (its name), the React component that paints each frame, how many frames long it is (durationInFrames), and its shape (width, height, fps). Registering a composition does not render anything; it just tells the studio and the renderer "a video called this exists, and here is how to draw it." You can register as many as you like; we register two.

Studio versus render

Remotion gives you two commands, and it helps to know which is which from the start.

  • Remotion Studio (npm run preview) opens a live editor in your browser. You pick a composition, drag a playhead along the timeline, and see each frame update instantly. Nothing is saved to disk; it is for building and checking.
  • Render (npm run render, covered on Step 11) runs through every frame once and writes the finished MP4 to a file. This is the step that actually produces airplane-2d.mp4.
What you should see. After npm install finishes and you run npm run preview, Remotion Studio opens in your browser and lists two compositions in the sidebar: Explainer2D and Explainer3D. Each shows as 1119 frames long at 30 fps, 1280×720. The canvas is still blank at this point because we have not written the drawing yet; that is Step 09.
Common mistakes.
  • Forgot npm install. If you run npm run preview straight away you get an error like Cannot find module 'remotion'. Run npm install first so the libraries exist in node_modules.
  • Wrong folder. The commands must run from the folder that holds package.json. If the terminal says could not determine executable to run or no such file, check you are in explainer-videos, not its parent.
  • Files in the wrong place. index.ts and Root.tsx must sit inside src/. If the import on line 2 of index.ts cannot find ./Root, the studio shows no compositions.
  • Old Node. A very old Node can fail to start Remotion. We used v24.15.0; a recent long-term-support version is fine.
Recap
  • Remotion turns a React component into an MP4: it asks your component for each frame, then packs the frames into a video.
  • A video is frames shown at a frame rate; ours is 30 fps, and the hook useCurrentFrame tells your component which frame to draw.
  • index.ts calls registerRoot; Root.tsx registers two compositions (Explainer2D and Explainer3D), each 1119 frames at 1280×720.
  • durationInFrames is 1119 because 37.295 s × 30 fps rounds up to 1119.
  • Studio (npm run preview) is the live editor; render (npm run render) writes the file. Both use the same component.
