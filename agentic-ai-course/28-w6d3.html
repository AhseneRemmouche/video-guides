What this day covers

A tour of more MCP servers, one of each kind: a knowledge-graph memory that runs entirely on your machine, Brave Search (a local server that calls a web service), a look at the rare remote servers, and market data from Polygon, first through our own small server and then through Polygon's official one. These are the parts the traders will use on Days 4 and 5.

TypeScript: pnpm lab3 runs every section, or pnpm lab3 memory, brave, market or polygon runs one. Brave needs BRAVE_API_KEY and is skipped without it. Without POLYGON_API_KEY, src/market.ts gives clearly labelled stand-in prices.

One helper does all the work in TypeScript: start a server, list its tools, run an agent with it.

/** Open a server, list its tools, then run an agent with it for each request (the "async with" cells). */
async function tryServer(params: Params, instructions: string, requests: string[], courseModel: string) {
  const server = new MCPServerStdio({ ...params, env: { ...networkEnv, ...params.env }, clientSessionTimeoutSeconds: 60 }); // networkEnv: see setup.ts
  await server.connect();
  try {
    console.log("tools:", (await server.listTools()).map((t) => t.name).join(", "));
    const agent = new Agent({ name: "agent", instructions, model: model(courseModel), mcpServers: [server] });
    for (const request of requests) {
      const result = await withTrace("conversation", () => run(agent, request));
      console.log(`\n> ${request}\n${result.finalOutput}\n`);
    }
  } finally {
    await server.close();
  }
}

Memory is just more tools (lecture 11)

mcp-memory-libsql gives "knowledge-graph based memory, a special kind of memory that understands about entities and observations about those entities and relationships between those entities". "People… think of memory like it's kind of one construct, perhaps because LangChain thinks of it" that way; here memory is simply tools the model can call. It is based on Anthropic's reference memory server but stores to a SQLite (libSQL) file you choose, so each trader can have its own. Market data from Polygon (lecture 13)

The free plan gives the previous day's closing prices and is heavily rate-limited; a paid plan ("somewhere between 20 and 30 bucks a month") gives prices 15 minutes late and unlimited calls; more money buys real-time prices. market.py has a "sneaky" trick for the free plan: one call that fetches the whole market's end-of-day prices counts as a single API call, so it is fetched once a day and cached, in memory and in the database's market table.

from polygon import RESTClient
from dotenv import load_dotenv
import os
from datetime import datetime
import random
from database import write_market, read_market
from functools import lru_cache
from datetime import timezone

load_dotenv(override=True)

polygon_api_key = os.getenv("POLYGON_API_KEY")
polygon_plan = os.getenv("POLYGON_PLAN")

is_paid_polygon = polygon_plan == "paid"
is_realtime_polygon = polygon_plan == "realtime"


def is_market_open() -> bool:
    client = RESTClient(polygon_api_key)
    market_status = client.get_market_status()
    return market_status.market == "open"


def get_all_share_prices_polygon_eod() -> dict[str, float]:
    """With much thanks to student Reema R. for fixing the timezone issue with this!"""
    client = RESTClient(polygon_api_key)

    probe = client.get_previous_close_agg("SPY")[0]
    last_close = datetime.fromtimestamp(probe.timestamp / 1000, tz=timezone.utc).date()

    results = client.get_grouped_daily_aggs(last_close, adjusted=True, include_otc=False)
    return {result.ticker: result.close for result in results}


@lru_cache(maxsize=2)
def get_market_for_prior_date(today):
    market_data = read_market(today)
    if not market_data:
        market_data = get_all_share_prices_polygon_eod()
        write_market(today, market_data)
    return market_data


def get_share_price_polygon_eod(symbol) -> float:
    today = datetime.now().date().strftime("%Y-%m-%d")
    market_data = get_market_for_prior_date(today)
    return market_data.get(symbol, 0.0)


def get_share_price_polygon_min(symbol) -> float:
    client = RESTClient(polygon_api_key)
    result = client.get_snapshot_ticker("stocks", symbol)
    return result.min.close or result.prev_day.close


def get_share_price_polygon(symbol) -> float:
    if is_paid_polygon:
        return get_share_price_polygon_min(symbol)
    else:
        return get_share_price_polygon_eod(symbol)


def get_share_price(symbol) -> float:
    if polygon_api_key:
        try:
            return get_share_price_polygon(symbol)
        except Exception as e:
            print(f"Was not able to use the polygon API due to {e}; using a random number")
    return float(random.randint(1, 100))
// Port of 6_mcp/market.py — share prices from Polygon.io, with the free plan's end-of-day prices cached in the database.
// Differences: plain fetch calls to Polygon's REST API replace the polygon-api-client package, so the functions are async.
// Without POLYGON_API_KEY the course returns random.randint(1, 100) on every call; here a clearly labelled STAND-IN
// gives repeatable fake prices (a fixed table plus a small daily wobble), so portfolios do not jump around on every refresh.
import { config } from "dotenv";
import { readMarket, writeMarket } from "./database.js";

config({ override: true, quiet: true });

const polygonApiKey = process.env.POLYGON_API_KEY;
const polygonPlan = process.env.POLYGON_PLAN;

export const isPaidPolygon = polygonPlan === "paid";
export const isRealtimePolygon = polygonPlan === "realtime";

const POLYGON = "https://api.polygon.io";

async function polygon(path: string): Promise<any> {
  const sep = path.includes("?") ? "&" : "?";
  const res = await fetch(`${POLYGON}${path}${sep}apiKey=${polygonApiKey}`);
  if (!res.ok) throw new Error(`Polygon ${res.status} ${res.statusText}`);
  return res.json();
}

export async function isMarketOpen(): Promise<boolean> {
  if (!polygonApiKey) return standInIsMarketOpen();
  const status = await polygon("/v1/marketstatus/now");
  return status.market === "open";
}

/** Every share's closing price on the last trading day, in one call (the free plan allows only a few calls a minute). */
async function getAllSharePricesPolygonEod(): Promise<Record<string, number>> {
  const probe = await polygon("/v2/aggs/ticker/SPY/prev"); // the previous close of SPY tells us the last trading day
  const lastClose = new Date(probe.results[0].t).toISOString().slice(0, 10);
  const grouped = await polygon(`/v2/aggs/grouped/locale/us/market/stocks/${lastClose}?adjusted=true&include_otc=false`);
  return Object.fromEntries((grouped.results ?? []).map((r: { T: string; c: number }) => [r.T, r.c]));
}

const memo = new Map<string, Record<string, number>>(); // stands in for @lru_cache

async function getMarketForPriorDate(today: string): Promise<Record<string, number>> {
  if (memo.has(today)) return memo.get(today)!;
  let marketData = readMarket(today);
  if (!marketData) {
    marketData = await getAllSharePricesPolygonEod();
    writeMarket(today, marketData);
  }
  memo.set(today, marketData);
  return marketData;
}

async function getSharePricePolygonEod(symbol: string): Promise<number> {
  const today = localDate(new Date());
  const marketData = await getMarketForPriorDate(today);
  return marketData[symbol] ?? 0.0;
}

async function getSharePricePolygonMin(symbol: string): Promise<number> {
  const result = await polygon(`/v2/snapshot/locale/us/markets/stocks/tickers/${symbol}`);
  return result.ticker?.min?.c || result.ticker?.prevDay?.c;
}

async function getSharePricePolygon(symbol: string): Promise<number> {
  return isPaidPolygon ? getSharePricePolygonMin(symbol) : getSharePricePolygonEod(symbol);
}

export async function getSharePrice(symbol: string): Promise<number> {
  if (polygonApiKey) {
    try {
      return await getSharePricePolygon(symbol);
    } catch (e) {
      console.error(`Was not able to use the polygon API due to ${e}; using a stand-in price`);
    }
  }
  return standInPrice(symbol, new Date());
}

// STAND-IN (not in the course): fake prices, used only when there is no POLYGON_API_KEY. NOT real market data.

const STAND_IN_BASE: Record<string, number> = {
  AAPL: 230, MSFT: 420, AMZN: 185, NVDA: 120, GOOGL: 165, META: 560, TSLA: 250, "BRK.B": 450, JPM: 210, KO: 63,
  JNJ: 155, XOM: 115, SPY: 560, QQQ: 480, VTI: 275, TLT: 92, GLD: 240, IBIT: 55, ETHA: 20, BITO: 21, ARKK: 50,
};

/** A number between 0 and 1 computed from a string, the same every time. */
function hash(text: string): number {
  let h = 2166136261;
  for (const ch of text) h = Math.imul(h ^ ch.charCodeAt(0), 16777619);
  return (h >>> 0) / 4294967296;
}

export function localDate(d: Date): string {
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, "0")}-${String(d.getDate()).padStart(2, "0")}`;
}

/** Fake price: a fixed base (unknown symbols get 1-100, like the course's random price) wobbling up to ±3% per day. */
export function standInPrice(symbol: string, day: Date): number {
  const s = symbol.toUpperCase();
  const base = STAND_IN_BASE[s] ?? 1 + Math.floor(hash(s) * 100);
  const wobble = (hash(`${s}|${localDate(day)}`) - 0.5) * 0.06;
  return Math.round(base * (1 + wobble) * 100) / 100;
}

/** Rough NYSE hours (Mon-Fri 9:30-16:00 New York time, holidays ignored), used when there is no Polygon key. */
function standInIsMarketOpen(): boolean {
  const ny = new Date(new Date().toLocaleString("en-US", { timeZone: "America/New_York" }));
  const minutes = ny.getHours() * 60 + ny.getMinutes();
  return ny.getDay() >= 1 && ny.getDay() <= 5 && minutes >= 9 * 60 + 30 && minutes < 16 * 60;
}

// Port of 6_mcp/market_server.py — an MCP server with one tool, lookup_share_price, wrapping market.ts.
// Without POLYGON_API_KEY the price comes from market.ts's labelled stand-in (fake prices), not from Polygon.
import { McpServer } from "@modelcontextprotocol/server";
import { serveStdio } from "@modelcontextprotocol/server/stdio";
import { z } from "zod";
import { getSharePrice } from "./market.js";

function createServer(): McpServer {
  const mcp = new McpServer({ name: "market_server", version: "1.0.0" });
  mcp.registerTool(
    "lookup_share_price",
    {
      description: "This tool provides the current price of the given stock symbol.",
      inputSchema: z.object({ symbol: z.string().describe("the symbol of the stock") }),
    },
    async ({ symbol }) => ({ content: [{ type: "text", text: String(await getSharePrice(symbol)) }] }),
  );
  return mcp;
}

Common mistakes

  • No memory/ folder: the libSQL URL file:./memory/ed.db needs it to exist.
  • Forgetting env: a server process does not see your .env; pass keys such as BRAVE_API_KEY explicitly.
  • Calling Polygon in a loop on the free plan: you hit the rate limit; rely on the cached end-of-day prices.
  • Giving a free-plan agent the official server: most of its tools fail; use the one-tool market_server.
  • Believing the prices without a key: they are random (Python) or stand-in (TypeScript) numbers.
Recap
  • Memory can be an MCP server: entities, observations and relations stored by tools.
  • Pass settings to a server process with env.
  • Brave Search is a local server calling a web API; remote servers exist but are rare.
  • Polygon's free plan works through one cached end-of-day call; a one-tool server keeps things simple.
  • Agents sometimes ignore instructions; a stronger model helped here.
