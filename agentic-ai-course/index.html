How this guide is organised

The course runs six weeks, five days each. Week 1 lays the foundations with raw API calls; Weeks 2 to 5 each take one agent framework (OpenAI Agents SDK, CrewAI, LangGraph, Microsoft AutoGen); Week 6 is the Model Context Protocol and the capstone trading floor. Every page below corresponds to one day and lists its lectures with timestamps so you can jump to the right place in the videos.

How the code was verified

Every code block on a day page comes from the course repository at commit 0fb280d5 (2 May 2026, the last state before the author's 2026 rewrite) or from this guide's TypeScript project; nothing is retyped by hand. The notebooks were executed cell by cell with the repository's locked package versions. No OpenAI key was available, so the runs used a local model (llama3.2 on Ollama) through the OpenAI-compatible endpoint, with email sending and the hosted web search replaced by stand-ins; each page says what its run proves and what it does not. The TypeScript projects type-check and build, and their React apps were driven in a headless browser.

The TypeScript projects are in the folders week1-ts to week6-ts next to these pages. Each has a README with its commands and an .env.example; run pnpm install in a folder, then the commands listed there.
