System Design Explained

A beginner-friendly system-design course for anyone starting out or preparing for a first system-design interview. Part 1, Foundations, builds a system up from a single server through databases, scaling, load balancing and designing out single points of failure. Part 2, API design, covers REST, GraphQL and gRPC, the protocols beneath them, TCP versus UDP, authentication, authorization and API security. Every idea is explained in plain language and carried by diagrams. To be honest about scope: the source video is titled as if it also teaches caching, CDNs and production infrastructure, but it actually delivers only these first two sections, so this guide covers Foundations and API design and no more.

About this guide

This is a concept course, not a coding project: there is no application to build and no repository to clone, so you will find explanations and diagrams rather than files to copy. The few small snippets along the way — a REST URL, a JSON response, a GraphQL query, a JWT's three parts — are there only to illustrate a point. Every diagram was redrawn from scratch as theme-aware inline SVG, so it reads cleanly in light and dark mode; the video's own frames are not reused. The definitions and claims follow standard, widely accepted system-design knowledge, and any made-up figures are labelled "illustrative".
