Background: AI, ML, Deep Learning and Neural Networks

The pre-course bonus material explained for beginners: how AI, machine learning and deep learning relate, and the main types of neural network.

This page is optional background. Before the course proper, the instructor ships a small bundle of bonus downloads (the "Five Pre Black Friday Extras"). Two of them are short illustrated hand-outs: one on how AI, machine learning and deep learning fit together, and one on the main kinds of neural network. You do not need any of this to write code, and there is nothing to type here. But if you have ever wondered where an LLM actually sits in the bigger picture of AI, these two pages give you a map. Everything below is explained in plain words, in our own diagrams; it is a friendly summary of those hand-outs, not a copy of them.

Why bother? The course is about one very specific kind of model. Knowing the family tree it belongs to makes later words — "deep", "parameters", "architecture", "generative" — stop sounding like jargon and start making sense.

Part 1 — How AI, machine learning and deep learning relate

The three terms get used as if they mean the same thing. They do not. They are nested: each one lives inside the one before it, like rings of a target.

  • Artificial intelligence (AI) is the broad goal: getting computers to do things we think of as needing human intelligence — making decisions, understanding text, recognising what is in a picture. It is the big umbrella, and it has many sub-fields such as robotics and computer vision.
  • Machine learning (ML) is one slice of AI. Instead of a programmer writing down every rule by hand, the machine learns the rules from examples and gets better at a task with experience. Every ML technique counts as AI — but not every AI is ML. A plain rule-based program (a long list of hand-written "if this, then that" rules) is AI, yet it never learns from experience, so it is not machine learning.
  • Deep learning (DL) is one slice of machine learning. It trains large neural networks — models loosely inspired by the brain, built from many stacked layers of simple units. "Deep" just means "many layers".
  • LLMs and generative AI live inside deep learning. The models this course uses are deep neural networks of a particular design, trained to generate text.
New to "subset"? What the nesting really means

When we say ML is a subset of AI, we mean every machine-learning method is also a kind of AI, but AI also contains other things that are not ML. Picture circles drawn one inside another: a dot in the smallest circle is also inside all the bigger ones. So an LLM is a piece of generative AI, which is deep learning, which is machine learning, which is artificial intelligence — all at once.

So what makes deep learning special inside machine learning? Deep learning trains deep artificial neural networks on large datasets such as images or text. The networks mimic the brain in a rough, mathematical way: many simple "artificial neurons" are wired together in layers, and the training process nudges the connections until the network does the job well. The more hidden layers you stack, the "deeper" the network.

New to supervised, unsupervised and reinforcement learning?

Machine learning splits into a few styles, and the hand-out names three:

  • Supervised learning — you train on labelled examples (input paired with the right answer), for tasks like classification.
  • Unsupervised learning — no labels; the model hunts for hidden patterns on its own, for example grouping similar items together (clustering).
  • Reinforcement learning — the model takes actions and learns from rewards, trying to collect as much reward as possible over time.

LLMs are trained mostly in a self-supervised way (predict the next word from plain text), then polished with human feedback — but that detail comes later in the course.

New to "features"? Why deep learning is different

A feature is a measurable clue the model uses to decide — the shape of an ear, the length of a word, the colour of a pixel. The hand-out's key point: with ordinary machine learning a human has to pick and prepare those clues by hand (manual feature extraction) before training a model. Deep learning skips that step: you feed in the raw data (such as images) with their labels, and the network works out the useful features by itself. That is the single biggest practical difference between the two.

Part 2 — The main types of neural network

Neural networks were first dreamed up in the 1950s, but sat unused for decades because computers were too weak to run them. Once they became practical, researchers found the most basic form could not solve every problem, so they invented new kinds of neuron and new ways to wire them up. The hand-out walks through the five most widely used types. We take them in the same order.

1. Perceptron / Feed-forward network (FFN) / Radial basis network

These are the most basic networks. Information flows in one direction — straight from input to output, layer after layer, never looping back. Inside every neuron sits one small piece of maths, usually written Wx + b:

  • x is an input value coming into the neuron.
  • W (the weight) says how much that input matters.
  • b (the bias) is a constant nudge added on top.

If a neuron has several incoming connections, it adds those values up first, then applies its Wx + b. The result can pass through an activation function before moving to the next layer. When that activation measures distance from a central point ("radial basis" functions), the network gets the historical name radial basis network. Stack several hidden layers between input and output and you have what people call a deep neural network. The weights and biases, by the way, are exactly the parameters you hear counted in the "billions" for big models.

Feed-forward networks suit problems where the input affects the output with no sense of time or order — the hand-out's example is reading the numbers from a blood test to judge whether a disease is present.

New to "neuron", "weight" and "bias"?

An artificial neuron is not a biological cell; it is a tiny calculator. It multiplies each input by a weight, adds them together, adds a bias, and passes the total on. Weights decide which inputs count and how much; the bias shifts the whole result up or down. Training a network just means slowly adjusting all those weights and biases until the output is right.

New to "activation function"?

After a neuron computes Wx + b, an activation function decides what to actually pass on. It adds a kink or curve so the network can model complicated, non-straight-line relationships. Without it, a deep stack of layers would collapse into one plain straight-line formula and could learn very little.

2. Recurrent neural network (RNN)

An RNN looks like a feed-forward network with one twist: each hidden neuron also receives its own result from the previous time step, not just the data from the layer behind it. That feedback gives the network a short-term memory, so it can treat the input as a sequence where order and timing matter. Because of this, RNNs are good at problems with a time dimension — the hand-out's example is forecasting the weather from a window of past climate readings.

3. Autoencoder

An autoencoder is built to squeeze information into a smaller space and then rebuild it. Its middle layer is deliberately narrow — fewer neurons than the input — so it is forced to keep only what matters. The first half, which compresses, is the encoder; the narrow middle is the code; the second half, which reconstructs, is the decoder. During training the output is simply a copy of the input, so the network learns to describe the data in less space while keeping enough to rebuild it. That makes autoencoders useful for compressing data for storage or transmission, or for producing a compact representation that another, specialised network can reuse.

4. Convolutional neural network (CNN)

A CNN has a different shape from the others. Its convolution layers slide small filters (little grids of numbers) across the data to pick out local patterns, while pooling steps shrink the result and keep the strongest signals. After a few rounds of this, the compact result is passed to an ordinary feed-forward network for the final decision. The hand-out's picture: a face-recognising CNN first spots edges and curves, then combines them into eyes, nose and mouth, and finally recognises the whole face. Its most common use is classifying images, but anything with local regularity — audio, for instance — can benefit too.

5. Generative adversarial network (GAN)

A GAN is really two networks in a contest. The generator tries to create content that looks like the real thing; the discriminator is the judge, comparing the generator's output against genuine examples and deciding whether each one is real or fake. Whenever the judge catches a fake, the generator is pushed to improve — and the two keep competing until the generator can fool the judge. Because the output was invented by the generator and accepted as convincing, GANs can produce brand-new content, which is why they are sometimes called "AI artists". It is a first, primitive taste of machine creativity.

The five at a glance

TypeKey ideaGood for
Perceptron / FFN / Radial basis Neurons compute Wx + b; information flows forward through layers (deep when many hidden layers are stacked). Problems where the input affects the output with no sense of time, e.g. judging a disease from blood-test numbers.
Recurrent (RNN) Neurons also feed their own previous result back in, adding a short memory of earlier steps. Sequence and time-based data, e.g. weather forecasting from past climate.
Autoencoder An encoder squeezes the input into a small code; a decoder rebuilds the original from it. Compression and compact representations for storage, transmission, or reuse by another network.
Convolutional (CNN / DCN) Filters scan for local patterns, pooling shrinks the result, then a feed-forward layer classifies. Images — and any data with local regularity, such as audio.
Generative adversarial (GAN) A generator and a discriminator compete until the fakes look real. Creating new content; sometimes called "AI artists".

Where this course's model fits

Notice that none of the five is the model this course actually uses. The architecture behind modern LLMs is the Transformer, introduced in 2017 — newer than every type above, and the one that made today's generative text models possible. It belongs to the same deep-learning family (it is still layers of weighted neurons trained on data) but is built to handle long stretches of text. The course meets it properly in Week 1 Day 4; treat this page as the backdrop that makes that day land.

Takeaway: AI > machine learning > deep learning > LLMs, each nested inside the last; and the five classic network types each solved a different kind of problem before the Transformer arrived.
