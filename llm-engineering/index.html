LLM Engineering · a beginner's companion

One page per course day. Each page explains the lessons in plain language, shows the exact code from the course (verified against the official repo), and records what was checked by running it. Every lab is shown in both Python and TypeScript (the TypeScript labs come with a small React web app), and the project is set up with uv. Written for people just starting as developers.

This guide uses uv (not Anaconda) for setup, and every Python lab has a TypeScript and React port (see the week1-ts project). You can read each code block in whichever language you prefer.

How this guide is organised

The course runs over eight weeks, and this guide follows it with one page per course day, plus a project-build page at the end of each week. All eight weeks are built. The days are grouped by week, just like the lessons. Week 1 teaches the basics of calling a large language model from Python: scraping a web page, summarising it with an OpenAI API call, comparing chat models, understanding tokens, and building a small brochure generator.

All eight weeks are available now (40 day pages and 8 project-build pages). Every lab is shown in both Python and TypeScript, each week ends with a step-by-step project-build page, and the project is set up with uv.

The model calls go either to the paid OpenAI API or to Ollama, a free program that runs a model on your own computer. The course, day by day

Week 1 · Build Your First LLM Product

Set up your environment with uv, call your first frontier model and your first local model, learn how LLMs actually work (tokens, context, cost), and build two real projects: a website summarizer and a company brochure generator. Every lab in Python and in TypeScript/React.

  1. 01Week 1 · Day 1 — Setup and Your First LLMSet up the project with uv, connect to OpenAI and to a local model with Ollama, and build a website summarizer - in Python and in TypeScript/React.~70 min
  2. 02Week 1 · Day 2 — Frontier vs Local: the Chat Completions APIThe Chat Completions API from the raw HTTP endpoint up to the openai client library, and OpenAI-compatible endpoints for Gemini and a free local Ollama model.~30 min
  3. 03Week 1 · Day 3 — Comparing the Frontier ModelsA guided tour of the leading chat models - GPT-4o, o1, Claude 3.5, Gemini, Cohere, Meta AI and Perplexity - and what each is good at.~45 min
  4. 04Week 1 · Day 4 — How LLMs Work: Transformers, Tokens, ContextFrom early AI to the transformer, then the ideas you use every day: parameters, tokens, the context window, API costs, and why a model has no memory.~45 min
  5. 05Week 1 · Day 5 — The Business Brochure ProjectCombine two LLM calls into a workflow: one picks the relevant links on a company site, the next writes a streamed markdown brochure - a first taste of agentic design.~50 min
  6. 06Week 1 · Project Build — Summarizer & Brochure, Step by StepBuild the Week 1 projects from an empty folder, step by step, in two stacks: Python with uv, and React + Node + TypeScript.build

Week 2 · Multi-Modal Chatbot: UIs, Tools and Agents

Call OpenAI, Claude and Gemini side by side; stream responses; put a web UI on your model (Gradio in Python, React in TypeScript); build a chatbot with memory; give the model tools it can call (function calling); and go multimodal with image and audio generation.

  1. 07Week 2 · Day 1 — Multiple APIs, Streaming and Adversarial ChatCall OpenAI, Anthropic Claude and Google Gemini from one notebook, stream their replies token by token, and make two models hold a conversation with each other.~40 min
  2. 08Week 2 · Day 2 — Put a UI on It: Gradio and ReactWrap your model in a web interface - Gradio for instant Python UIs, and a React app (Vite + a Hono API) for the TypeScript version.~45 min
  3. 09Week 2 · Day 3 — Chatbots with History and ContextBuild a conversational assistant that remembers the conversation, with a system prompt and multi-shot context to shape its answers.~35 min
  4. 10Week 2 · Day 4 — Tools: Giving the Model Function CallingBuild an AI airline assistant that can call your own functions - how you describe a tool, how the model asks to use it, and how you run it and return the result.~45 min
  5. 11Week 2 · Day 5 — Multimodal: Images and AudioAdd an image tool with DALL-E 3 and a voice with text-to-speech, and combine tools into a single multimodal agent.~40 min
  6. 12Week 2 · Project Build — Chat App with Tools, Step by StepBuild the Week 2 multimodal chat assistant from scratch in two stacks: a Gradio app with Python + uv, and a streaming React chat app with a Hono API in Node + TypeScript.build

Week 3 · Open-Source Gen AI with HuggingFace

Leave the paid APIs for a week and run open-source models yourself: the HuggingFace Hub and Google Colab, the high-level pipelines API, tokenizers for Llama/Phi/Qwen, loading and quantizing models, and a project that turns an audio recording into written meeting minutes. Python on a GPU, with a TypeScript/React port using transformers.js.

  1. 13Week 3 · Day 1 — The HuggingFace Hub and Google ColabExplore the HuggingFace Hub (models, datasets, spaces), set up a free Google Colab GPU notebook, and add your HuggingFace token as a Colab secret.~45 min
  2. 14Week 3 · Day 2 — HuggingFace PipelinesThe high-level pipelines API: sentiment, named-entity recognition, question answering, summarization, translation, classification, text and image generation - a few lines each.~30 min
  3. 15Week 3 · Day 3 — Tokenizers for Open-Source ModelsAutoTokenizer for Llama 3.1, Phi-3, Qwen2 and Starcoder: encoding, decoding, special tokens and chat templates, and why each model tokenizes differently.~40 min
  4. 16Week 3 · Day 4 — Running and Quantizing Open-Source ModelsLoad a model with AutoModelForCausalLM, shrink it with 4-bit quantization (bitsandbytes), generate text and stream the output, and watch the memory footprint.~45 min
  5. 17Week 3 · Day 5 — Meeting Minutes from AudioCombine a frontier model and an open-source model: transcribe a recording with Whisper, then write tidy markdown meeting minutes with Llama - plus a synthetic test-data generator.~35 min
  6. 18Week 3 · Project Build — Open-Source Toolkit, Step by StepBuild the Week 3 open-source tools from scratch: pipelines, tokenizers and a quantized model in Python + uv (on a Colab/GPU), and a transformers.js version with a React UI in Node + TypeScript.build

Week 4 · LLM Showdown: Picking a Model and Generating Code

How to choose the right model: scaling laws, the limits of benchmarks, and the leaderboards and arenas that compare models. Then a real project - use frontier and open-source models to rewrite slow Python as high-performance C++ - with a React UI in TypeScript.

  1. 19Week 4 · Day 1 — How to Choose the Right LLMThe things that actually matter when picking a model: open vs closed, the Chinchilla scaling law, and why benchmarks can mislead (overfitting and training-data leakage).~50 min
  2. 20Week 4 · Day 2 — Leaderboards and ArenasThe leaderboards and human-rated arenas that compare models - the HuggingFace Open LLM Leaderboard, specialized leaderboards, and the LMSYS Chatbot Arena - and commercial use cases.~50 min
  3. 21Week 4 · Day 3 — Code Generation: Python to Fast C++Use GPT-4o and Claude 3.5 to rewrite slow Python as high-performance C++ (speedups of thousands of times), with a Gradio UI in Python and a React UI in TypeScript.~60 min
  4. 22Week 4 · Day 4 — Open-Source Code ModelsRun open-source code models (like CodeQwen) through HuggingFace Inference Endpoints and compare them with the frontier models on the same code task.~45 min
  5. 23Week 4 · Day 5 — Evaluating What You BuiltMeasure results two ways: model-centric metrics (speed, correctness) and business-centric metrics (does it solve the real problem?), plus a harder challenge to try.~25 min
  6. 24Week 4 · Project Build — The Code Optimizer, Step by StepBuild the Python-to-C++ code optimizer from scratch: a Gradio app in Python + uv, and a two-pane React app (paste Python, get optimized C++) with a Hono API in Node + TypeScript.build

Week 5 · Mastering RAG with LangChain

Give a model your own documents. Build Retrieval-Augmented Generation from scratch, then with LangChain: chunk text, turn it into vector embeddings, store them in a vector database (Chroma/FAISS), retrieve the relevant pieces and feed them to the model - ending with a personal AI knowledge worker. Python and a LangChain.js + React port.

  1. 25Week 5 · Day 1 — RAG Fundamentals and Vector EmbeddingsWhat RAG is and why it helps, a do-it-yourself RAG with no libraries, and the key idea underneath it all - vector embeddings that place meaning in space.~40 min
  2. 26Week 5 · Day 2 — LangChain: Loaders, Splitters, EmbeddingsMeet LangChain: load documents, split them into overlapping chunks with a text splitter, and turn them into OpenAI embeddings ready for a vector database (Chroma).~35 min
  3. 27Week 5 · Day 3 — Vector Stores and Visualizing EmbeddingsStore embeddings in Chroma, then actually see them: project the high-dimensional vectors down to 2-D/3-D with t-SNE to watch similar documents cluster together.~40 min
  4. 28Week 5 · Day 4 — The Full RAG Pipeline in LangChainPut it together: a retriever finds the relevant chunks, the LLM answers from them, and conversation memory keeps the chat coherent - the complete RAG chain.~40 min
  5. 29Week 5 · Day 5 — Debugging RAG and the Knowledge WorkerFix common RAG problems (bad retrieval, wrong chunks), swap vector stores (FAISS vs Chroma), look behind LangChain's curtain, and build a personal AI knowledge worker.~55 min
  6. 30Week 5 · Project Build — AI Knowledge Worker, Step by StepBuild a personal AI knowledge worker over your own documents: a LangChain + Gradio app in Python + uv, and a LangChain.js RAG app with a React chat UI in Node + TypeScript.build

Week 6 · Fine-tuning a Frontier Model (the Product Pricer)

Build a real data-science project: predict a product's price from its description. Curate a big dataset, build traditional machine-learning baselines, see how far frontier models get out of the box, then fine-tune a frontier model with OpenAI's fine-tuning API. Training is Python + uv; a small React app demos the finished pricer.

  1. 31Week 6 · Day 1 — From Inference to Training: Curating DataThe shift from using models to training them. Where training data comes from, and how to curate and scrub a dataset of product descriptions and prices.~50 min
  2. 32Week 6 · Day 2 — Prompting vs RAG vs Fine-tuning, and Big DatasetsWhen to prompt, when to use RAG, and when to fine-tune; the deployment pipeline; and building a large, balanced dataset - then uploading it to the HuggingFace Hub.~60 min
  3. 33Week 6 · Day 3 — Traditional ML BaselinesBefore any LLM: feature engineering, a bag-of-words count vectorizer, and classic models (linear regression, SVR, random forest) as baselines to beat.~65 min
  4. 34Week 6 · Day 4 — How Well Do Frontier Models Price?Test GPT-4o-mini and Claude on the pricing task out of the box, compare them with the baselines and with humans, and see where frontier models shine.~45 min
  5. 35Week 6 · Day 5 — Fine-tuning with OpenAIPrepare JSONL training data, launch a fine-tuning job with the OpenAI API, track training and validation loss with Weights & Biases, and evaluate the result - including when fine-tuning does not help.~60 min
  6. 36Week 6 · Project Build — The Product Pricer, Step by StepBuild the product pricer: curate data, train baselines and fine-tune a model in Python + uv, then wire the finished model to a small React demo UI (enter a description, get a price) in Node + TypeScript.build

Week 7 · QLoRA: Fine-tuning an Open-Source Model

Can a small open-source model, fine-tuned, rival the frontier? Fine-tune Llama with QLoRA (4-bit quantization plus low-rank adapters) to predict prices, track it with Weights & Biases, and compare it head-to-head with the frontier models. Training is Python + uv on a GPU; the finished model drives the same pricer demo.

  1. 37Week 7 · Day 1 — QLoRA and Loading the Base ModelThe idea behind QLoRA: freeze a 4-bit quantized open-source model and train tiny low-rank adapters on top. Load Llama in 4-bit and prepare the pricing dataset.~70 min
  2. 38Week 7 · Day 2 — Evaluating the Base ModelMeasure the open-source model before fine-tuning: an evaluation harness that runs it over the test set and scores its price predictions, as a starting point.~50 min
  3. 39Week 7 · Day 3 — The QLoRA Training RunSet up LoRA adapters (rank, alpha, target modules) and the training configuration (TRL's SFTTrainer), and launch the fine-tune on a GPU.~60 min
  4. 40Week 7 · Day 4 — Monitoring and HyperparametersWatch training with Weights & Biases, understand the key hyperparameters (learning rate, epochs, batch size, quantization), and save the adapter to the Hub.~45 min
  5. 41Week 7 · Day 5 — Does It Beat the Frontier?Load the fine-tuned adapter, evaluate it on the test set, and compare the open-source result head-to-head with the frontier models and the baselines.~65 min
  6. 42Week 7 · Project Build — The Open-Source Pricer, Step by StepFine-tune an open-source model with QLoRA in Python + uv (on a Colab/GPU), then point the Week 6 React pricer demo at your fine-tuned model's endpoint.build

Week 8 · The Autonomous Agent System

The capstone: an autonomous multi-agent system that hunts for underpriced deals. A planning agent coordinates a scanner, an ensemble of pricing models (frontier, your fine-tuned open-source model, and a RAG pricer), and a messaging agent that alerts you - with a dashboard to watch it work. Python + uv for the system, with a React dashboard demo.

  1. 43Week 8 · Day 1 — The Agent System and Structured OutputsWhat an agentic system is, the architecture of the deal-hunting project, and structured outputs - making models return reliable, typed data your code can use.~55 min
  2. 44Week 8 · Day 2 — Deploying the Pricer and the EnsembleDeploy the fine-tuned model to the cloud (Modal) as a service, then combine several pricing models - frontier, your fine-tuned model, and a RAG pricer - into one ensemble estimate.~75 min
  3. 45Week 8 · Day 3 — Structured Outputs and the Scanner AgentMake the model return reliable typed data with structured outputs (Pydantic), then build the scanner agent that finds candidate deals and the messaging agent that sends alerts.~45 min
  4. 46Week 8 · Day 4 — Agents That CollaborateThe agent framework: a planning agent coordinates a scanner agent (finds deals), the ensemble pricer, and a messaging agent - each doing one job and handing off to the next.~45 min
  5. 47Week 8 · Day 5 — The Price is Right: the Full SystemBring it together into an autonomous system with a dashboard and push notifications that finds and alerts you to real underpriced deals - the finished course project.~50 min
  6. 48Week 8 · Project Build — The Deal-Hunting System, Step by StepBuild the autonomous deal-hunting system in Python + uv - the agent framework, ensemble pricer and notifications - and a React dashboard demo (Node + TypeScript) that shows the deals it finds.build
