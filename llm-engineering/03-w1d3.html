Week 1 · Day 3 — Comparing the Frontier Models

A guided tour of the leading chat models - GPT-4o, o1, Claude 3.5, Gemini, Cohere, Meta AI and Perplexity - and what each is good at.

Companion to Ed Donner's course · uv setup · Python + TypeScript/React · code verified against the repo

Today is a tour, not a coding day. The instructor opens the chat websites of six leading AI companies and asks each one the same handful of questions, so you can build an intuition for where each model is strong, where it is weak, and when you would pick which. There is no notebook and no code on this page. Instead we compare the models side by side, exactly as the video does.

The goal he states up front: get to know these frontier models well enough that you can think about how you would apply them to a real business problem, and choose the right one for a job. These are also the very same models you will later call from your own Python code by API — today you just meet them through their web apps first.

The six companies on the tour

The instructor looks at six companies and their large language models (LLMs):

  1. OpenAI — the famous GPT family, shown through the ChatGPT website. He uses two of its models: GPT-4o and o1-preview (a reasoning model).
  2. Anthropic — OpenAI's main competitor, also in San Francisco, founded by people who left OpenAI. Its model is Claude, shown as Claude 3.5 Sonnet.
  3. Google — Gemini, the model you now often see answering a Google search. It was previously called Bard.
  4. Cohere — a Canadian AI company. Its model is shown as Command Plus and is known for drawing on a wealth of background knowledge.
  5. Meta — the Llama model. This is an open-source model, and Meta also runs a web app, Meta AI, that lets you chat with it.
  6. Perplexity — the odd one out. Perplexity is a search engine powered by LLMs. It can use other companies' models behind the scenes, and also has its own.

What all of them are good at

Before comparing them, the instructor points out what these models do well across the board. Every one of them is excellent at:

  1. Structured, well-researched answers. Give a detailed, nuanced question and you get back a clear summary with an introduction and a conclusion.
  2. Fleshing out notes. Hand it a few bullet points and ask for an email, a blog post or a slide, and it builds it out. You can then give feedback and iterate — the “copilot” way of working.
  3. Writing and debugging code. The instructor describes pasting a tricky error and stack trace into Claude and getting back both a precise explanation and the fix.

And where they are weak: specialised, expert-level subject matter (most are not yet at PhD level in a narrow field); recent events, because each model has a training cutoff date and will not know what happened since; and odd blind spots where they state a wrong answer with the same confidence as a right one. That last point — confident mistakes, sometimes called hallucination — is the one to watch.

New here? What is an LLM, and what is a “frontier” model?

An LLM (large language model) is a program trained on huge amounts of text that predicts likely next words, which lets it answer questions, write and summarise. A frontier model is simply one of the largest, most capable models of the moment — the ones at the leading edge. The six companies here all ship frontier models. The instructor's big takeaway is that, at the frontier, these models are converging: for a typical question you get excellent, similar answers from all of them, so price and speed increasingly become the deciding factor.

GPT-4o and o1-preview: a standard model next to a reasoning model

The tour starts with OpenAI. GPT-4o handles the “soft” business question — how do I decide if a business problem is suitable for an LLM solution? — with a nicely structured, reasoned answer. But on a trick question (“how many times does the letter A appear in this sentence?”) GPT-4o got it wrong, answering five when the real answer is four. This is not really about intelligence; it is about how text is first chopped into tokens before the model sees it, which Day 4 explains with the tokenizer.

The instructor then switches to o1-preview, OpenAI's strongest model at the time (originally codenamed “strawberry”, Pro subscribers only). It uses a chain-of-reasoning approach: you can see it think — “counting letter frequencies… taking a closer look” — and it takes noticeably longer. This time it got the letter count right (four) and also solved the word-analogy puzzle. That is the whole idea of a reasoning model: think first, answer second.

What is a reasoning model?

Most chat models answer in one shot: your prompt goes in, an answer comes straight out. A reasoning model is trained to first work through a problem step by step — a “chain of reasoning” — before giving its final answer. In the video you can literally watch o1-preview narrate its thinking (“counting letter frequencies…”) and take longer to respond. The payoff is better results on tasks that need careful logic, like the letter-counting puzzle it got right while the others got wrong. The trade-off is that it is slower and, at the time, needed a paid Pro plan.

GPT-4o has one more trick the instructor shows: Canvas. When you say “use canvas”, a panel opens on the right where the model and you work on code together — it rewrites and extends the code as you give loose, plain-English instructions (“only yield unique authors”, “simplify this”), building example data and improving the solution as it goes. Because GPT-4o is multimodal, it can also generate images on request.

Claude: alignment and Artifacts

Claude from Anthropic is described as the instructor's favourite and the favourite of most data scientists, with Claude 3.5 Sonnet leading most benchmarks at the time. Two things stood out. First, alignment and safety: asked to rank itself against other models, Claude politely pushed back — it said it was not comfortable making comparative claims — and instead described only its own strengths and weaknesses. Second, Artifacts: when asked for example code, Claude put it in a separate panel on the right that you can publish or download, and each new request produced a new artifact so you can look back at earlier versions.

What does “alignment and safety” mean here?

Alignment means shaping a model so its behaviour matches human values and intentions — being honest about what it will and will not do, and avoiding harmful or misleading answers. In the tour this showed up as Claude declining to make comparative claims about rival models and being clear about its limits (for example, stating its knowledge cutoff rather than guessing about current events). It is a deliberate design priority for Anthropic, not an accident.

Gemini, Cohere, Meta AI and Perplexity

The instructor moves faster through the rest. Gemini (Google) gave thorough answers but was overly literal on a playful, humorous question, missing the joke that GPT-4o had understood. Command Plus (Cohere, a Canadian company) gave structured, detailed answers that clearly drew on a lot of background knowledge, though it noted it has no image abilities. Meta AI is the web front end to the open-source Llama model; its answers were fine but less powerful than the top models, and it did image generation well. Several of these still got the letter-counting question wrong.

Finally Perplexity, the odd one out. It is a search engine powered by LLMs, so it shines on factual, current-events questions: the instructor asked who had just been elected and got back a researched, sourced summary. It also happened to count the letters correctly. Like Claude, it declined the “compare yourself to other models” question.

What is Perplexity? (retrieval + LLM)

Most chat models answer only from what they learned during training, so they can be out of date or make things up. Perplexity works differently: it first searches the web for relevant, current information, then feeds what it finds to an LLM to write the answer. That pattern — fetch real documents first, then let the language model compose the reply — is why Perplexity returns sources and does well on up-to-the-minute questions. It can even use other companies' models underneath. The trade-off is that it is aimed at factual research rather than open-ended chat.

The same models you will soon call by code

One important point for the rest of the course: the chat websites you clicked through today are backed by the exact same frontier models you will soon call from Python by API. Meeting them in a browser first builds intuition; later you send them the same kinds of prompts from your own code and read the answers back programmatically. During inference — the moment a trained model actually answers — the model behind the website and the model behind the API are one and the same.

Try them yourself. You can repeat this tour for free in a browser — no code needed. Open each company's chat website (for example ChatGPT, Claude, Gemini, Meta AI and Perplexity), sign in, and ask them all the same question. Good questions are ones that bring out the differences: a nuanced business question, a playful or trick question, or a current-events question. Watch how a reasoning model like o1-preview thinks before answering, and notice which models return sources.
Before you rely on any of this. These models change often: names, versions and even which one is “best” move month to month, so your results will differ from the video and from this page — treat model names as values you can swap. Models can also be confidently wrong (hallucinate), so check anything that matters. And never paste secrets — passwords, API keys, private customer data — into a chat UI; assume anything you type could be stored.
Video vs repo. This page follows what the instructor demonstrates in the videos: GPT-4o, o1-preview, Claude 3.5 Sonnet, Gemini, Command Plus, Llama and Perplexity.
