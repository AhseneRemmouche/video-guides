The finished app

"It's a real-time weather dashboard where you can access the weather data at any latitude and longitude coordinates across the entire planet" (00:52). You pick a city from a dropdown, or click anywhere on the map, and every card updates with the weather for that place. All the data comes from OpenWeather, a weather service you call over the internet.

New to React? What it is and why this project uses it

React is a JavaScript library for building user interfaces. Instead of changing the page by hand ("find this element, change its text"), you describe what the screen should look like for the current data, and React updates the page for you whenever the data changes.

You describe the screen with components: functions that return JSX, an HTML-like syntax inside JavaScript. The dashboard is a tree of them: App contains the dropdowns, the map, four cards and the side panel; each card contains smaller pieces. You will write your first component on the next page.

This video uses React 19. The code in the video only uses features that React 18 already had, so most of what you learn also applies to React 18 projects (the project itself still needs React 19, because react-leaflet 5 requires it). Step 29 switches the code to the newer React 19 forms.

New to APIs? How the app gets real weather data

An API (application programming interface) is a way for one program to ask another for data. Here, your app sends a web address such as https://api.openweathermap.org/data/3.0/onecall?lat=35.68&lon=139.69&... to OpenWeather's server, and the server answers with text in JSON format: the temperature, the forecast, and so on.

To use OpenWeather you need an API key, a long secret string that identifies your account. Step 05 shows how to get one and where to store it.

Before you start: check your tools

  1. Install Node.js and a code editor

    You need Node.js (which includes npm) and an editor. The presenter uses VS Code with the Prettier extension (visible in the status bar), and their terminal is Git Bash on Windows (the prompt says MINGW64). Any terminal works. Vite 7 needs Node.js 20.19 or newer (or 22.12+); this guide was checked with Node 24. Download the LTS ("long-term support") version from nodejs.org if you do not have it.

  2. Check the versions in a terminal 
    node --version
npm --version

    Line by line

    Line(s)CodeWhat it does & why
    1node --versionRuns Node.js and asks only for its version (the --version flag), for example v24.15.0.   • node --version prints a version of at least v20.19 (or v22.12).
  • npm --version prints a version number without errors.

Common mistakes

  • An old Node.js. Vite 7 no longer supports Node 18: the dev server fails to start or crashes with a confusing error. Install the current LTS and open a new terminal.
  • Expecting the free OpenWeather plan to cover everything. The main weather API used from step 05 on (One Call 3.0) needs a separate "One Call by Call" subscription on your OpenWeather account. Without it every weather card fails. Step 05 explains this before you write any code.
  • Copying keys from the video. The presenter shows their keys on screen and says they delete them before publishing. Always create your own.
