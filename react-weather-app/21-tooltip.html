New to tooltips and Radix? What the four pieces do

A tooltip needs more than a hidden div: it must open on hover and keyboard focus, close on Escape or when the pointer leaves, be positioned next to the trigger and flip if there is no room, and link itself to the trigger for screen readers. Radix UI handles all of that in unstyled components; shadcn copies a styled wrapper into src/components/ui/tooltip.tsx. The pieces:

  • Tooltip: the root. Holds the open/closed state.
  • TooltipTrigger: the thing you hover or focus. By default Radix renders it as a <button>.
  • TooltipContent: the box that appears. It is rendered in a portal: at the end of <body>, not inside the panel. That is why it can be hidden behind the panel and why its z-index matters.
  • TooltipProvider: shared settings such as the delay before opening. The shadcn wrapper adds one inside every Tooltip, with delayDuration = 0, so tooltips open immediately.
New to asChild? Let the child be the trigger

Many Radix parts accept asChild. Without it, <TooltipTrigger> renders its own <button> and puts your content inside. With it, Radix renders no element of its own and merges its event handlers and attributes into your single child instead. That is how the shadcn example turns a shadcn Button into the trigger without nesting a button in a button. For an icon, leaving asChild out is actually better: the generated <button> can be reached with the Tab key, so keyboard users can open the tooltip too.

New to stacking and z-index across portals?

Because TooltipContent is moved to the end of <body>, it competes for "on top" with the side panel, which is fixed with z-1001. The shadcn styles give the content z-50. 50 is less than 1001, so the box was drawn under the panel: it opened, but you couldn't see it. className="z-2000" on TooltipContent is merged by cn() (tailwind-merge), which replaces z-50 rather than adding a second z-index.

The shadcn component (briefly)

You don't need to edit this file, but it helps to know what you are using:

import * as React from "react"
import * as TooltipPrimitive from "@radix-ui/react-tooltip"

import { cn } from "@/lib/utils"

function TooltipProvider({
  delayDuration = 0,
  ...props
}: React.ComponentProps<typeof TooltipPrimitive.Provider>) {
  return (
    <TooltipPrimitive.Provider
      data-slot="tooltip-provider"
      delayDuration={delayDuration}
      {...props}
    />
  )
}

function Tooltip({
  ...props
}: React.ComponentProps<typeof TooltipPrimitive.Root>) {
  return (
    <TooltipProvider>
      <TooltipPrimitive.Root data-slot="tooltip" {...props} />
    </TooltipProvider>
  )
}

function TooltipTrigger({
  ...props
}: React.ComponentProps<typeof TooltipPrimitive.Trigger>) {
  return <TooltipPrimitive.Trigger data-slot="tooltip-trigger" {...props} />
}

function TooltipContent({
  className,
  sideOffset = 0,
  children,
  ...props
}: React.ComponentProps<typeof TooltipPrimitive.Content>) {
  return (
    <TooltipPrimitive.Portal>
      <TooltipPrimitive.Content
        data-slot="tooltip-content"
        sideOffset={sideOffset}
        className={cn(
          "bg-foreground text-background animate-in fade-in-0 zoom-in-95 data-[state=closed]:animate-out data-[state=closed]:fade-out-0 data-[state=closed]:zoom-out-95 data-[side=bottom]:slide-in-from-top-2 data-[side=left]:slide-in-from-right-2 data-[side=right]:slide-in-from-left-2 data-[side=top]:slide-in-from-bottom-2 z-50 w-fit origin-(--radix-tooltip-content-transform-origin) rounded-md px-3 py-1.5 text-xs text-balance",
          className
        )}
        {...props}
      >
        {children}
        <TooltipPrimitive.Arrow className="bg-foreground fill-foreground z-50 size-2.5 translate-y-[calc(-50%_-_2px)] rotate-45 rounded-[2px]" />
      </TooltipPrimitive.Content>
    </TooltipPrimitive.Portal>
  )
}

export { Tooltip, TooltipTrigger, TooltipContent, TooltipProvider }

What you should see

A small circled "i" next to "AQI" and next to each pollutant name. Hovering one opens a small box at once, with dark text on a light background in dark mode (inverted colours). The AQI box wraps over a few lines. Each pollutant shows "Concentration of …" with its full name, for example "Concentration of Carbon monoxide" for Co and "Concentration of Fine particles matter" for Pm2_5. You can also press Tab to reach an icon and the tooltip opens on focus.

Common mistakes

  • Hover does nothing: the content is behind the panel. Add a z-index above 1001 to TooltipContent.
  • "Concentration of" with no name: missing .toUpperCase().
  • "Cannot find name 'Button'": you kept the shadcn example's trigger. Use the icon instead (or install the button with npx shadcn@latest add button).
  • Icon invisible: the SVG is dark grey (#292929) and the background is dark. In this step the video used invert; after step 24 the global .dark svg rule handles it.
  • Import path: import Information from "/src/assets/information.svg?react". Without ?react you get a URL string, not a component.

Tooltips don't open on touch screens

Radix tooltips are made for mouse and keyboard. In the installed @radix-ui/react-tooltip source, pointer movement from a touch is ignored and a click (tap) closes the tooltip. So on a phone, tapping the (i) icon shows nothing (read from the source, not tested on a device). That is fine for extra hints, but don't put information that phone users need only in a tooltip. A shadcn Popover, which opens on click, is the usual alternative.
