Project Setup

Create a React + TypeScript project with Vite and clean out the starter files.

▶ Watch this part (01:10)

Goal

Create a new React + TypeScript project with Vite, see it running in the browser, understand every file Vite generated, and then wipe the demo content so you start "from a completely clean slate" (03:21). This chapter runs from 01:07 to 05:29 in the video.

Why Vite? In the presenter's words: "Vite is a build tool that takes all of your React files and builds them into the actual app that you see on a web page" (01:07), and "Vite is pretty much the industry standard now as it's a fast and super efficient build tool" (02:13). The command used here is "my preferred way of getting your React app up and running super quickly".

New to npm? Packages, npm and npx in two minutes

A package is a bundle of code someone published so others can reuse it: React, Vite and Tailwind are all packages. npm (Node Package Manager) downloads packages from the public npm registry into a folder called node_modules inside your project, and records them in package.json.

npx runs a package's command without installing it permanently. npm create vite@latest is a shortcut: npm turns it into "run the package create-vite at its latest version", which is exactly what the terminal prints (> npx, > create-vite).

Two kinds of packages end up in a project: dependencies, which the app needs while it runs (React), and dev dependencies, which are only tools for building and checking (Vite, TypeScript, ESLint).

New to TypeScript? Why the files end in .ts and .tsx

TypeScript is JavaScript plus types: you can say "this value is a number" or "this object has lat and lon", and the editor warns you, while you type, when the code does not match. Browsers do not understand TypeScript, so tools strip the types away before the code runs.

.ts files contain only TypeScript. .tsx files may also contain JSX (the HTML-like syntax), so every component file ends in .tsx. In this project Vite removes the types when serving the code, and tsc (the TypeScript compiler) only checks the types; it never writes JavaScript files ("noEmit": true below).

Common mistakes

  • Running commands in the wrong folder. npm run dev says Missing script: "dev" or "Could not read package.json". Run cd weather-project first; the terminal must be in the folder that contains package.json.
  • Port already in use. If another dev server is running, Vite picks the next port (5174) and says so. Use the address the terminal prints.
  • Deleting App.css but not its import (or the other way round). Vite shows an overlay saying it failed to resolve ./App.css. Remove the import line.
  • Deleting the whole index.css file. main.tsx still imports it, so you get the same kind of error. Keep the file; empty it if you like.
  • A white page instead of dark grey. You deleted the :root block too. Harmless, but your screen will look different from the video until step 03.
  • Selecting "TypeScript + SWC" or "JavaScript". SWC works but differs from the repository; JavaScript gives .jsx files without types, and nothing in this guide will match. Start again with React and TypeScript.
