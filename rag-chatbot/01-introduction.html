The problem

ChatGPT can write poetry, explain quantum physics and write whole applications. But ask it about your company's policies, research papers or personal notes and it has no idea. The model was never trained on your private data.

ChatGPT is built on a large language model (LLM): a program that has read a huge amount of public text and learned to predict which words should come next. It only "knows" what was in that text, up to the date its training stopped. Your company handbook was never part of it.

This project fixes that with a RAG chatbot that turns any PDF into knowledge the AI can use straight away. Upload an employee handbook, then ask "What is our vacation policy?" and the bot answers from the handbook.

RAG stands for Retrieval-Augmented Generation. In one sentence: before the AI answers, your app looks up the most relevant passages in your own documents and gives them to the AI to read. The next page explains it in detail.

New to web apps? What "frontend", "backend" and "API" mean here

A web app usually has two halves:

  • The frontend is what runs in the user's browser: the pages, buttons and chat box they see and click.
  • The backend (the server) is code that runs on a computer you control. It can keep secrets, such as your OpenAI key, and talk to databases.

The two halves talk to each other over the internet by sending HTTP requests and responses, just like your browser does when it loads any website. An API is simply a set of addresses (URLs) that a program can send requests to and get data back from. OpenAI offers an API; your app will also have its own small API at /api/chat.

In this project, Next.js lets you write both halves in one project, in one language (TypeScript).

What you will build

  • A chat interface that streams in real time: /chat, built with AI Elements. "Streams" means the answer appears word by word as it is being written, like in ChatGPT, instead of all at once after a long wait. See streaming.
  • PDF upload and processing: /upload extracts the text, splits it into chunks and embeds each chunk.
  • Vector embeddings for semantic search, stored in Neon Postgres with pgvector. Semantic search means "search by meaning": a question about "time off" can find a passage about "vacation days" even though the words differ.
  • A tool-calling AI that searches the knowledge base before it answers. A "tool" is a function in your code that the AI is allowed to ask your app to run.
  • Authentication and role-based access control with Clerk. Only signed-in users can chat, and only admins can upload. Authentication answers "who are you?"; role-based access control answers "what are you allowed to do?".

The paths such as /chat and /upload are the parts of the web address after the domain. While you develop, the full address is http://localhost:3000/chat, where localhost means "this computer".

Before you start

  • Node.js 18.18+ and npm. Recent Node 20/22 is best.
  • An OpenAI API key (platform.openai.com).
  • A free Clerk account (clerk.com) and a free Neon account (neon.com).
  • Some React and TypeScript experience. The video recommends watching Codevolution's AI SDK playlist first.

Here is what each item is, why you need it and how to get it.

1. A terminal and a code editor

You will type commands into a terminal and edit files in a code editor. Any editor works; the video uses VS Code, which is free and has a terminal built in (menu Terminal → New Terminal, or Ctrl+`).

New to the terminal? What it is and why it matters

A terminal (also called command line, shell or console) is a text window where you type commands instead of clicking. You type a command, press Enter, and the computer prints the result.

The terminal is always "standing in" one folder, called the current directory. Commands act on that folder. Three commands you will use all the time:

  • cd folder-name moves into a folder ("change directory"). cd .. moves up one level.
  • mkdir folder-name creates a new folder ("make directory").
  • ls (macOS/Linux/PowerShell) or dir (Windows cmd) lists what is in the current folder.

On Windows you can use PowerShell or the VS Code terminal. On macOS use the Terminal app. In this guide, lines inside boxes marked sh are commands to type into the terminal.

2. Node.js and npm

Node.js is a program that runs JavaScript outside the browser, on your computer or a server. Next.js, its development server and all the build tools are written in JavaScript, so they need Node.js to run. npm (Node Package Manager) is installed together with Node.js. It downloads ready-made code libraries (packages) that other people have published, such as the AI SDK.

Check whether you already have them. Open a terminal and run:

node -v
npm -v

node -v asks Node.js to print its version (-v is short for "version"). npm -v does the same for npm.

What you should see: two version numbers, for example v22.11.0 and 10.9.0. The first number after the v must be 18 or higher (and, for 18, at least 18.18). 20 or 22 is best.

If you don't have Node.js, or it is too old: go to nodejs.org, download the LTS ("Long Term Support", the stable version) installer for your system and run it. Then close and reopen your terminal and run the two commands again.

Common mistakes

  • "node is not recognized" or "command not found: node": Node.js is not installed, or the terminal was opened before installing. Close every terminal window (and VS Code) and open a new one.
  • An old version such as v16 shows up: install the current LTS from nodejs.org. Next.js 15 will refuse to run on it.

3. An OpenAI API key

Your app sends questions to OpenAI's models over the internet. OpenAI needs to know who is asking (and who to bill), so every request carries an API key. Create one at platform.openai.com/api-keys with Create new secret key, then copy it somewhere safe. It starts with sk-. OpenAI shows it only once.

New to API keys? What they are and why they are secret

An API key is like a password for a program. Anyone who has your key can make requests as you, and OpenAI will charge your account. That is why:

  • You never paste it into code that runs in the browser (anyone can read that code).
  • You never commit it to Git or post it online.
  • You keep it in a special file, .env.local, that only the server reads. You will create that file in step 4.

The OpenAI API is pay-as-you-go. You need to add a small amount of credit (a few dollars is plenty for this project) under Billing, otherwise requests fail with a quota error.

4. Clerk and Neon accounts

  • Clerk handles sign-up, sign-in and user roles for you, so you don't have to build login pages and store passwords yourself. You will use it from step 7. Sign up for free at clerk.com; you will create the application later.
  • Neon hosts a Postgres database in the cloud with a free tier, so you don't need to install a database on your computer. You will use it from step 9. Sign up for free at neon.com.

5. Some React and TypeScript

React is the library used to build the user interface out of reusable pieces called components. TypeScript is JavaScript plus types: labels that say what kind of value a variable holds, so your editor can catch mistakes before you run the code. This guide explains every line, but basic familiarity with JavaScript (variables, functions, objects, arrays) will make it much easier.

New to file trees? How to read the diagram below

A file tree shows folders and files as an indented list. The top line is the project folder. Each ├── or └── is one item inside the folder above it (└── just marks the last item). A name ending in / is a folder. The vertical │ lines show which folder an item belongs to.

So src/app/chat/page.tsx means: the file page.tsx, inside the folder chat, inside app, inside src. The notes on the right ("← step 9") tell you which step creates or edits the file.

Files starting with a dot, like .env.local, are normal files. The dot just marks them as configuration files, and some systems hide them by default.

A quick map of the main areas, so the names feel familiar later:

  • src/app/: the pages and server endpoints. In the Next.js App Router, the folder path becomes the URL: src/app/chat/page.tsx is the page at /chat, and src/app/api/chat/route.ts is the endpoint at /api/chat.
  • src/components/: reusable pieces of user interface. ui/ and ai-elements/ are generated for you by command-line tools in step 4; you won't write them by hand.
  • src/lib/: helper code that is not a page, such as the database connection, the chunking function and the search function.
  • migrations/: SQL files generated from your database schema; they describe how to create the tables.
  • .env.local: your secret keys. Never shared, never committed.

Don't worry about creating these now. Each step tells you exactly which file to create and where.
