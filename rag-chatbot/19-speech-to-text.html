Speech to Text

Ask questions with your voice: record, transcribe, send.

Extension · code type-checked against the repo

Goal

Add a microphone button to the prompt box. Click it, speak your question, and click it again to stop. The recording is transcribed and the text lands in the textarea, so you can check it before pressing send.

"Transcribed" means converted from spoken audio into written text. This is called speech to text (STT). The next step does the reverse, text to speech (TTS).

Two halves work together: the browser records your voice (it is the only side that can reach the microphone), and the server sends the recording to OpenAI (it is the only side that can safely hold your API key).

New to MediaRecorder and getUserMedia? How a web page records audio

Browsers give pages two built-in tools for this:

  • navigator.mediaDevices.getUserMedia({ audio: true }) asks the user "May this site use your microphone?". If they allow it, you get a MediaStream: a live flow of sound from the mic. If they refuse, or there is no microphone, it throws an error.
  • new MediaRecorder(stream) takes that live stream and records it into a compressed audio file. While it records, it hands you pieces of the file (chunks) through the ondataavailable event. When you call stop(), it fires onstop, and you glue the chunks together into one Blob (a file in memory).

Permissions: the browser remembers the user's answer per site. If someone clicks "Block" by accident, they must re-allow it in the address bar (the padlock or mic icon next to the URL). Your code can't override that, which is why the hook shows a friendly error message instead.

A stream also has tracks (one per device, here one audio track). As long as a track is running, the browser shows a red "recording" indicator. Stopping every track is how you really turn the microphone off.

Why the route calls OpenAI directly

The AI SDK has a transcribe() helper (exported as experimental_transcribe), but in the repo's version (ai 5.0.47) it doesn't work with browser recordings. Its source shows why:

  • transcribe() works out the audio format by checking the first bytes of the file. It only recognises MP3, WAV, OGG, FLAC and AAC, and anything else is labelled "audio/wav".
  • Browsers record WebM (Chrome, Edge, Firefox) or MP4 (Safari), so the OpenAI provider would upload your recording as audio.wav when it is actually WebM or MP4.

So the route sends the file to OpenAI's /v1/audio/transcriptions endpoint itself, with the correct file extension. It needs about 15 lines and no extra package.

New to audio formats and MIME types? What "audio/webm;codecs=opus" means

A MIME type (or media type) is a standard label that says what kind of data a file contains, written as category/format: image/png, application/pdf, audio/webm.

Audio files have two layers:

  • The container (WebM, MP4, OGG, WAV) is the "box" format: it organises the data and stores details like duration. This is the part after the slash.
  • The codec (Opus, AAC, MP3) is how the sound itself is compressed. Browsers sometimes add it as a parameter after a semicolon: audio/webm;codecs=opus.

Different browsers pick different containers: Chrome, Edge and Firefox usually record audio/webm, and Safari records audio/mp4. The file extension (.webm, .mp4) is another hint servers use to guess the format, which is why the route builds a matching file name. MP3's MIME type is the odd one out: it's audio/mpeg, not audio/mp3.

Step by step

  1. Create the transcription route
    • Read the uploaded audio field from req.formData().
    • Normalise the media type: "audio/webm;codecs=opus" → "audio/webm".
    • Reject unknown types and anything over 25 MB, OpenAI's upload limit, which is roughly 25+ minutes of compressed speech.
    • Re-upload the file to OpenAI with a matching file name (recording.webm, recording.mp4…) and model: "gpt-4o-mini-transcribe".
    • Return { text } as JSON. If OpenAI fails, log its error message on the server and return a generic error to the browser.

    Create the folders src/app/api/transcribe/ and, inside, a file named exactly route.ts. In the App Router, that folder path becomes the URL /api/transcribe and the file is a route handler.

    // src/app/api/transcribe/route.ts
const ALLOWED_TYPES = [
  "audio/webm",
  "audio/mp4",
  "audio/ogg",
  "audio/mpeg",
  "audio/wav",
];
const MAX_BYTES = 25 * 1024 * 1024; // OpenAI's limit for transcription uploads

export async function POST(req: Request) {
  try {
    const formData = await req.formData();
    const audio = formData.get("audio");

    if (!(audio instanceof File) || audio.size === 0) {
      return Response.json({ error: "No audio provided" }, { status: 400 });
    }

    // "audio/webm;codecs=opus" -> "audio/webm"
    const mediaType = audio.type.split(";")[0];
    if (!ALLOWED_TYPES.includes(mediaType)) {
      return Response.json(
        { error: `Unsupported audio type: ${mediaType}` },
        { status: 400 },
      );
    }
    if (audio.size > MAX_BYTES) {
      return Response.json({ error: "Recording is too long" }, { status: 400 });
    }

    const extension =
      mediaType === "audio/mpeg" ? "mp3" : mediaType.split("/")[1];
    const body = new FormData();
    body.append("file", audio, `recording.${extension}`);
    body.append("model", "gpt-4o-mini-transcribe");

    const res = await fetch("https://api.openai.com/v1/audio/transcriptions", {
      method: "POST",
      headers: { Authorization: `Bearer ${process.env.OPENAI_API_KEY}` },
      body,
    });

    if (!res.ok) {
      console.error("OpenAI transcription error:", await res.text());
      return Response.json(
        { error: "Failed to transcribe audio" },
        { status: 502 },
      );
    }

    const { text } = (await res.json()) as { text: string };
    return Response.json({ text });
  } catch (error) {
    console.error("Transcription error:", error);
    return Response.json(
      { error: "Failed to transcribe audio" },
      { status: 500 },
    );
  }
}

  2. Create the recorder hook

    useVoiceRecorder(onTranscript) wraps the browser's MediaRecorder API:

    • start() asks for microphone permission (getUserMedia), creates a MediaRecorder and collects audio chunks as they arrive.
    • stop() stops recording. The recorder's onstop handler then turns the microphone off (stops every track, so the browser's recording indicator goes away), joins the chunks into one Blob with the recorder's real mimeType, and uploads it.
    • transcribe() POSTs the blob as FormData and passes the text to your callback.
    • It exposes isRecording, isTranscribing and error so the button can show its state.
    New to custom hooks? Packaging stateful logic into a reusable function

    A hook is a function whose name starts with use and that can call other hooks such as useState and useRef. React ships built-in hooks; a custom hook is one you write yourself.

    Custom hooks let you move a chunk of logic (here: permissions, recording, uploading, and three state values) out of the page into its own file. The page then just writes:

    // illustrative only
const recorder = useVoiceRecorder((text) => console.log(text));
recorder.start();          // begin recording
recorder.isRecording;      // true while recording

    Each component that calls the hook gets its own copy of the state. Two rules apply to every hook: call it only at the top level of a component or another hook (not inside an if or a loop), and only in Client Components, which is why the file starts with "use client".

    The hook also uses useRef. A ref is a box (ref.current) that keeps a value between renders without causing a re-render when it changes. That fits the recorder object and the list of chunks: you need to keep them, but the screen doesn't need to update when they change.

    Create a new folder src/hooks/ (it doesn't exist yet) and add this file:

    // src/hooks/use-voice-recorder.ts
"use client";

import { useRef, useState } from "react";

export function useVoiceRecorder(onTranscript: (text: string) => void) {
  const [isRecording, setIsRecording] = useState(false);
  const [isTranscribing, setIsTranscribing] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const recorderRef = useRef<MediaRecorder | null>(null);
  const chunksRef = useRef<Blob[]>([]);

  const transcribe = async (recording: Blob) => {
    setIsTranscribing(true);
    try {
      const formData = new FormData();
      formData.append("audio", recording);

      const res = await fetch("/api/transcribe", {
        method: "POST",
        body: formData,
      });
      const data = (await res.json()) as { text?: string; error?: string };
      if (!res.ok || data.text === undefined) {
        throw new Error(data.error ?? "Transcription failed");
      }
      onTranscript(data.text);
    } catch (err) {
      setError(err instanceof Error ? err.message : "Transcription failed");
    } finally {
      setIsTranscribing(false);
    }
  };

  const start = async () => {
    setError(null);
    try {
      const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
      const recorder = new MediaRecorder(stream);
      chunksRef.current = [];

      recorder.ondataavailable = (event) => {
        if (event.data.size > 0) chunksRef.current.push(event.data);
      };
      recorder.onstop = () => {
        for (const track of stream.getTracks()) track.stop(); // turn the mic off
        const recording = new Blob(chunksRef.current, {
          type: recorder.mimeType,
        });
        void transcribe(recording);
      };

      recorder.start();
      recorderRef.current = recorder;
      setIsRecording(true);
    } catch {
      setError("Microphone access was denied or is unavailable");
    }
  };

  const stop = () => {
    recorderRef.current?.stop();
    recorderRef.current = null;
    setIsRecording(false);
  };

  return { isRecording, isTranscribing, error, start, stop };
}

  3. Wire it into the chat page

    Four changes to src/app/chat/page.tsx:

    1. Import MicIcon, SquareIcon and Loader2Icon from lucide-react, PromptInputButton from the prompt-input module, and the hook.
    2. Call the hook. The callback appends the transcript to whatever is already typed: setInput((prev) => (prev ? `${prev} ${text}` : text)).
    3. Add a PromptInputButton next to the + menu. It shows a mic icon when idle, a red stop square while recording and a spinner while transcribing, and it is disabled during transcription.
    4. Show recorder.error in the same red message line as the attachment errors, for example when microphone permission is denied.

    lucide-react is the icon library that came with shadcn/ui, so it's already installed. Each icon is a small React component.

Complete file

// src/app/chat/page.tsx
"use client";

import { Fragment, useState } from "react";
import { useChat } from "@ai-sdk/react";
import { Loader2Icon, MicIcon, SquareIcon } from "lucide-react";
import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from "@/components/ai-elements/conversation";
import { Message, MessageContent } from "@/components/ai-elements/message";
import {
  PromptInput,
  PromptInputActionAddAttachments,
  PromptInputActionMenu,
  PromptInputActionMenuContent,
  PromptInputActionMenuTrigger,
  PromptInputAttachment,
  PromptInputAttachments,
  PromptInputBody,
  PromptInputButton,
  type PromptInputMessage,
  PromptInputSubmit,
  PromptInputTextarea,
  PromptInputToolbar,
  PromptInputTools,
} from "@/components/ai-elements/prompt-input";
import { Response } from "@/components/ai-elements/response";
import { Loader } from "@/components/ai-elements/loader";
import { toDataUrlParts } from "@/lib/to-data-url";
import { useVoiceRecorder } from "@/hooks/use-voice-recorder";

export default function RAGChatBot() {
  const [input, setInput] = useState("");
  const [formKey, setFormKey] = useState(0);
  const [inputError, setInputError] = useState<string | null>(null);
  const { messages, sendMessage, status } = useChat();
  const recorder = useVoiceRecorder((text) =>
    setInput((prev) => (prev ? `${prev} ${text}` : text)),
  );

  const handleSubmit = async (message: PromptInputMessage) => {
    const text = message.text?.trim() ?? "";
    const hasFiles = Boolean(message.files?.length);
    if (!text && !hasFiles) {
      return;
    }

    const files = hasFiles
      ? await toDataUrlParts(message.files ?? [])
      : undefined;

    if (text) {
      sendMessage({ text, files });
    } else if (files) {
      sendMessage({ files });
    }

    setInput("");
    setInputError(null);
    setFormKey((key) => key + 1); // remount PromptInput to clear its attachments
  };

  return (
    <div className="max-w-4xl mx-auto p-6 relative size-full h-[calc(100vh-4rem)]">
      <div className="flex flex-col h-full">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map((message) => (
              <div key={message.id}>
                {message.parts.map((part, i) => {
                  switch (part.type) {
                    case "text":
                      return (
                        <Fragment key={`${message.id}-${i}`}>
                          <Message from={message.role}>
                            <MessageContent>
                              <Response>{part.text}</Response>
                            </MessageContent>
                          </Message>
                        </Fragment>
                      );
                    case "file":
                      if (!part.mediaType.startsWith("image/")) {
                        return null;
                      }
                      return (
                        <Fragment key={`${message.id}-${i}`}>
                          <Message from={message.role}>
                            <MessageContent>
                              {/* biome-ignore lint/performance/noImgElement: data: URLs can't go through next/image optimisation */}
                              <img
                                src={part.url}
                                alt={part.filename ?? "Attached image"}
                                className="max-h-64 rounded-md"
                              />
                            </MessageContent>
                          </Message>
                        </Fragment>
                      );
                    default:
                      return null;
                  }
                })}
              </div>
            ))}
            {(status === "submitted" || status === "streaming") && <Loader />}
          </ConversationContent>
          <ConversationScrollButton />
        </Conversation>

        {(inputError || recorder.error) && (
          <p className="mt-2 text-sm text-destructive">
            {inputError ?? recorder.error}
          </p>
        )}

        <PromptInput
          key={formKey}
          onSubmit={handleSubmit}
          className="mt-4"
          accept="image/png,image/jpeg,image/webp,image/gif"
          multiple
          maxFiles={4}
          maxFileSize={4 * 1024 * 1024}
          onError={(err) => {
            // PromptInput reuses the form's onError prop for file errors
            if ("code" in err) setInputError(err.message);
          }}
        >
          <PromptInputBody>
            <PromptInputAttachments>
              {(attachment) => <PromptInputAttachment data={attachment} />}
            </PromptInputAttachments>
            <PromptInputTextarea
              value={input}
              onChange={(e) => setInput(e.target.value)}
            />
          </PromptInputBody>
          <PromptInputToolbar>
            <PromptInputTools>
              <PromptInputActionMenu>
                <PromptInputActionMenuTrigger />
                <PromptInputActionMenuContent>
                  <PromptInputActionAddAttachments label="Add images" />
                </PromptInputActionMenuContent>
              </PromptInputActionMenu>
              <PromptInputButton
                onClick={recorder.isRecording ? recorder.stop : recorder.start}
                disabled={recorder.isTranscribing}
                variant={recorder.isRecording ? "destructive" : "ghost"}
                aria-label={
                  recorder.isRecording ? "Stop recording" : "Record a question"
                }
              >
                {recorder.isTranscribing ? (
                  <Loader2Icon className="size-4 animate-spin" />
                ) : recorder.isRecording ? (
                  <SquareIcon className="size-4" />
                ) : (
                  <MicIcon className="size-4" />
                )}
              </PromptInputButton>
            </PromptInputTools>
            <PromptInputSubmit disabled={!input && !status} status={status} />
          </PromptInputToolbar>
        </PromptInput>
      </div>
    </div>
  );
}

Test it

  1. Click the microphone. The browser asks for permission. Allow it, and the button turns red with a stop icon.
  2. Say "What is our vacation policy?", then click stop. A spinner shows briefly, then the text appears in the prompt box.
  3. Edit if needed and press send. The RAG flow works exactly as for typed questions.
  4. Deny permission (or open the page with no microphone). The message "Microphone access was denied or is unavailable" appears.

How to know it worked: while recording, the browser tab shows a red recording dot and the mic button is red. Right after you click stop, that dot disappears (the tracks were stopped). In DevTools' Network tab you'll see a POST to transcribe with status 200 and a response like {"text":"What is our vacation policy?"}.

Common mistakes:

  • 404 on /api/transcribe – the file isn't at src/app/api/transcribe/route.ts (check the folder name and that the file is called route.ts, not transcribe.ts).
  • "Failed to transcribe audio" and a 401 error in the terminal – OPENAI_API_KEY is missing or wrong in .env.local. If you just edited that file, restart the dev server; environment variables are only read at start-up.
  • "Unsupported audio type" – your browser recorded a format not in ALLOWED_TYPES. The message shows the type; it is usually a browser-specific variant you can add to the list if OpenAI supports it.
  • The permission pop-up never appears – you blocked the mic for this site earlier. Click the icon at the left of the address bar and allow the microphone, then reload.
  • "Cannot find module '@/hooks/use-voice-recorder'" – the hooks folder must be inside src/, not at the project root.

Secure context required. Browsers only allow microphone access on https:// pages or http://localhost. If you open the dev server from another device using your LAN IP (for example http://192.168.1.20:3000), the microphone is blocked. Use an HTTPS tunnel or deploy the app.

Recap
  • MediaRecorder records in the browser. /api/transcribe forwards the audio to OpenAI with the correct file type.
  • The transcript fills the prompt box instead of sending straight away, so users can fix any mistakes first.
  • The AI SDK's transcribe() isn't used here because version 5.0.47 mislabels browser recordings (WebM and MP4) as WAV.
