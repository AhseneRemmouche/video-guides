Setting Up the Project

Create the Next.js app with TypeScript, Tailwind and the App Router.

▶ Watch this part (02:07)

Goal

Create an empty Next.js app that every later step builds on. The video creates it in the current directory, a folder named aisdk-rag-chatbot.

Next.js is a framework built on top of React. React builds user interfaces; Next.js adds everything else a real website needs: pages with URLs, server code, a development server and a production build. You don't create all of that by hand. A tool called create-next-app generates a working starter project for you in about a minute.

New to packages, npm and npx? What they are and why they matter

A package is a bundle of code someone has published so others can reuse it. Next.js itself is a package. So are the AI SDK, Tailwind and hundreds of small helpers.

  • npm downloads packages into your project (into a folder called node_modules) and records them in package.json.
  • npx (installed with npm) downloads a package that is a command-line tool and runs it once, without adding it to your project. That is perfect for one-off generators such as create-next-app.

Rule of thumb: npm install something = "my app needs this library"; npx something = "run this tool for me now".

Step by step

  1. Create the folder and open a terminal in it 
    mkdir aisdk-rag-chatbot
cd aisdk-rag-chatbot

    Line by line

    Line(s)CodeWhat it does & why
    1mkdir aisdk-rag-chatbotmkdir means "make directory". It creates a new, empty folder called aisdk-rag-chatbot inside whatever folder the terminal is currently in. Choose a sensible parent first, for example a projects folder in your home directory. Folder names should be lowercase with dashes, no spaces: npm package names cannot contain capital letters or spaces, and create-next-app uses the folder name as the project name.
    2cd aisdk-rag-chatbotcd means "change directory". It moves the terminal into the new folder, so the next command creates the project there. Without it, the files would land in the parent folder.

    Tip: in VS Code you can now use File → Open Folder… and choose aisdk-rag-chatbot. Its built-in terminal (Ctrl+`) then opens directly in the right folder.

  2. Run create-next-app in the current directory

    The . tells the CLI to scaffold here instead of creating a new subfolder.

    npx create-next-app@latest .

    Line by line

    Line(s)CodeWhat it does & why
    1npxDownload and run a command-line package once, without installing it into the project.
    1create-next-appThe official Next.js project generator. It asks a few questions and then writes all the starter files and installs the packages they need.
    1@latestUse the newest published version of the generator, not an older copy that may be cached on your computer. Without it, npx might reuse an outdated version.
    1.In the terminal, a single dot means "the current folder". It tells the generator to put the project right here, in aisdk-rag-chatbot. Without it, the tool asks for a project name and creates another folder inside this one.

    The first time, npx may ask "Need to install the following packages: create-next-app@… Ok to proceed? (y)". Press y then Enter. A "scaffold" is just a ready-made starting structure, like scaffolding around a building.

    Common mistake: if the folder already contains files (for example a stray notes.txt), create-next-app may refuse with a message that the directory contains files that could conflict. Use an empty folder.

  3. Answer the prompts exactly like the video

    The generator asks a series of yes/no or multiple-choice questions. Use the arrow keys to move between choices and Enter to confirm. For yes/no questions you can also press y or n.

    PromptAnswerWhy
    TypeScript?YesEvery file in the project is .ts/.tsx, and the AI SDK types are a big help.
    Linter?BiomeA fast linter and formatter. You can see biome.json in the video's file tree.
    Tailwind CSS?Yesshadcn/ui and AI Elements are styled with Tailwind.
    src/ directory?YesAll code lives under src/. The paths in later steps assume this.
    App Router?YesRoute handlers, server actions and app/ folders depend on it.
    Turbopack?YesFaster dev server.
    Customize import alias?NoKeeps the default @/* → src/* alias, which the code uses (for example @/lib/db-config).

    What each choice means, in plain words:

    • TypeScript: JavaScript with types. You write .ts files (plain code) and .tsx files (code that also contains HTML-like JSX). Your editor then warns you, for example, if you pass a number where text is expected, before you ever run the app.
    • Linter (Biome): a linter reads your code and flags likely bugs and style problems; a formatter fixes spacing and quotes automatically. Biome does both in one fast tool. The other option, ESLint, works too, but the video uses Biome.
    • Tailwind CSS: a way of styling by putting short class names directly on elements, such as p-4 (padding) or text-sm (small text), instead of writing separate CSS files.
    • src/ directory: puts your application code in a src ("source") folder, keeping it apart from configuration files in the project root. Purely organisational, but every path in this guide assumes it.
    • App Router: the modern Next.js way of defining pages: folders inside src/app become URLs. The older alternative ("Pages Router") does not support the features used later.
    • Turbopack: a newer, faster engine that rebuilds your app when you save a file during development.
    • Import alias: a shortcut for file paths. With @/*, you can write import { db } from "@/lib/db-config" from any file instead of counting folders with "../../lib/db-config". The @ stands for src.

    After the last answer, the tool creates the files and runs npm install for you. This can take a minute and prints a lot of text. Wait until you see a line like "Success! Created aisdk-rag-chatbot at …".

    Newer versions may ask one extra question, for example about React Compiler. If a question is not in the table, accept the default (just press Enter).

  4. Start the dev server 
    npm run dev

    Line by line

    Line(s)CodeWhat it does & why
    1npm runRun a named script from the "scripts" section of package.json. Scripts are shortcuts for longer commands.
    1devThe script name. create-next-app defined it as next dev --turbopack: start the Next.js development server with Turbopack.

    The development server is a program that keeps running in your terminal. It builds your pages on request, serves them at http://localhost:3000, and watches your files: when you save a change, the browser updates automatically (this is called hot reload). It is meant for development only; real deployments use npm run build then npm run start.

    What you should see in the terminal: something like ▲ Next.js 15.x (Turbopack), - Local: http://localhost:3000 and ✓ Ready in …. The command does not "finish": the terminal stays busy while the server runs. That is normal.

    To stop the server, click in that terminal and press Ctrl+C (on macOS too, it is Ctrl, not Cmd). If asked "Terminate batch job (Y/N)?" on Windows, type y. To start it again, run npm run dev again. While it runs, open a second terminal for other commands (in VS Code, the + button in the terminal panel).

  5. Open the app

    Go to http://localhost:3000.

    localhost means "this computer", and 3000 is the port, a numbered door on your computer that the dev server listens on. Only you can see this address; it is not on the internet.

    Expected result: the default Next.js welcome page.

    Common mistakes

    • "This site can't be reached": the dev server is not running (you stopped it, or closed the terminal). Run npm run dev again.
    • The terminal says "Port 3000 is in use, using available port 3001": another server is already running, often an old one in a forgotten terminal. Either open the address it prints (localhost:3001), or stop the old server with Ctrl+C.
    • "Missing script: dev" or "Could not read package.json": the terminal is in the wrong folder. Run cd aisdk-rag-chatbot (or open the folder in VS Code) and try again.

What you have now

aisdk-rag-chatbot/ ├── biome.json ├── next.config.ts ├── package.json ├── tsconfig.json ├── public/ └── src/ └── app/ ├── favicon.ico ├── globals.css ├── layout.tsx └── page.tsx

What each file and folder is for:

ItemWhat it is
biome.jsonSettings for Biome, the linter and formatter: which rules to check and how to format code. You won't need to change it.
next.config.tsSettings for Next.js itself. Empty at first; step 12 adds an option to it.
package.jsonThe project's "ID card" (package.json): its name, the scripts (dev, build, start, lint…) and the lists of packages it depends on (dependencies and devDependencies). Every npm install adds a line here.
tsconfig.jsonSettings for TypeScript, including the @/* → ./src/* path alias you kept in the prompts.
public/Static files (images, icons) served as-is. A file public/logo.png is available at /logo.png.
src/app/The App Router folder. Every folder inside it that contains a page.tsx becomes a page.
src/app/favicon.icoThe little icon shown in the browser tab.
src/app/globals.cssCSS that applies to the whole site. It loads Tailwind. shadcn/ui adds colour variables to it in step 4.
src/app/layout.tsxThe root layout: the outer HTML (<html>, <body>, fonts) that wraps every page. Step 7 adds the Clerk provider and navigation bar here.
src/app/page.tsxThe home page at /: the welcome page you just saw.

You will also see some files the tree above leaves out because you won't edit them: node_modules/ (the downloaded packages, often hundreds of megabytes, never edit or commit it), package-lock.json (the exact installed version of every package, so installs are repeatable), .gitignore (tells Git which files not to track, such as node_modules and .env* files), next-env.d.ts (TypeScript types for Next.js), postcss.config.mjs (wires Tailwind into the CSS pipeline) and README.md.

Version note: the video uses the create-next-app version that was current when it was recorded (Next.js 15.x). On a newer major version the prompts may be worded a little differently. Keep the same choices.

Recap
  • You created a Next.js App Router project with TypeScript, Tailwind, Biome, a src/ folder and the default @/ alias.
  • The dev server runs on port 3000.
  • Start it with npm run dev, stop it with Ctrl+C.
