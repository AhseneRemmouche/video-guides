What Is LangChain?

A framework that wraps models, messages, tools and agents so you can build AI apps fast.

▶ Watch this part (05:02)

Goal

Before writing code, you need a clear picture of what LangChain is and what it does for you. In this part of the video (05:02–08:33) the presenter reads the official definition and explains the key idea: LangChain is an abstraction layer that lets you build AI applications fast without handling every low-level detail yourself. This page explains that idea with examples, compares plain API code with LangChain code, and previews LangGraph, which LangChain is built on.

The official definition (05:02)

The presenter searches "what is LangChain" and reads the description from LangChain's creators: a framework for building agents and LLM-powered applications. It helps you chain together components and third-party integrations to simplify AI application development. Their summary: "LangChain's whole goal is to simplify our AI development."

Let's unpack the three key words in that sentence.

New to LLMs? What a large language model is

A large language model (LLM) is a program trained on huge amounts of text. You give it text (a prompt) and it continues it, one small piece of text (a token) at a time. Chat versions of these models, called chat models, are trained to continue a conversation, which is why they answer questions.

The models used in this course do not run on your computer. They run on the servers of a provider such as OpenAI. Your program sends the prompt over the internet and receives the answer. Running the model to produce an answer is called inference, and the provider charges you a small amount per token for it.

New to frameworks? What "framework" and "abstraction layer" mean

A library is code you call when you need it. A framework is a larger set of libraries plus a way of organising your app; you fit your code into its structure. LangChain is a framework installed as a Python package.

An abstraction hides details behind a simpler interface. Think of driving a car: you press the accelerator, and you do not control the fuel injection yourself. LangChain is the accelerator. Underneath, it still makes the same network requests to OpenAI that you could write by hand, but you write one line instead of twenty, and the line is the same whichever provider you use.

The trade-off, which the presenter points out at 07:00: details give you control. Sometimes you need that control. Very often you do not, and you would rather "ship fast" and get a working proof of concept quickly.

Agents

An agent is a model that can take actions through tools, look at the results, and decide what to do next. The presenter's example (06:32): a model that "can search online because I am given the toolkit of searching online". You build exactly that in step 09.

LLM-powered applications

An LLM-powered application is any program where a language model does part of the work. The presenter stresses (06:09) that a real application is more than "inputs and outputs, inputs and outputs". Around the model call you usually need instructions, tools, a memory of the conversation, files such as images, and checks on what comes back. LangChain gives you a ready-made piece for each of these.

"Chain together components and third-party integrations"

The name comes from this idea: you connect (chain) parts such as a model, a prompt, a tool and a memory into one flow. Third-party integrations are connections to outside services: model providers (OpenAI, Anthropic, Google…), search services such as Tavily, databases and more. Each comes as a separate small package, for example langchain-openai, which you install in step 04.

Without LangChain vs with LangChain

To see what the abstraction saves, compare the same tiny task, "ask the model a question and print the answer", written two ways. These are illustrative snippets for comparison; you do not need to run them. Step 04 builds the real LangChain version.

Version A: calling OpenAI directly with the official openai package (which LangChain also uses under the hood):

from openai import OpenAI

client = OpenAI()
completion = client.chat.completions.create(
    model="gpt-5-nano",
    messages=[{"role": "user", "content": "What is the capital of Italy?"}],
)
print(completion.choices[0].message.content)

Version B: the same with LangChain, the style you write from step 04 on:

from langchain.chat_models import init_chat_model

model = init_chat_model("gpt-5-nano")
response = model.invoke("What is the capital of Italy?")
print(response.content)

Line(s)CodeWhat it does & why

For one question, the difference looks small. It grows fast once you add the features the chef needs: tools, the loop that runs them, memory and images. The diagram lists what you would have to write yourself.

Where LangChain sits

LangChain does not contain any model. It sits between your code and the provider. When you call model.invoke(...), LangChain translates your request into the provider's format, the provider package sends it over the internet, and the answer comes back up the same path.

Providers

A provider is the company (or local program) that runs the model. The course uses OpenAI's gpt-5-nano everywhere because it is cheap, which matters while you are learning. LangChain supports many others; each needs its own integration package and its own API key. Model names change often, so treat those below as examples at the time of writing.

LangChain vs LangGraph: a preview (05:45)

The presenter mentions LangGraph and promises a full comparison in a later video. Here is the short version, so the name does not surprise you when it appears in your code.

  • LangGraph is a lower-level library from the same team. You describe your app as a graph: boxes (nodes) that do work, and arrows (edges) that say what runs next. It gives you full control over every step, and it is "very powerful", as the presenter says, but you write more code.
  • LangChain (version 1.x, used here) gives you ready-made, high-level pieces. Its create_agent function, which you use from step 05, builds a LangGraph graph for you and returns it. That is why LangGraph is installed automatically with LangChain, and why memory in step 10 is imported from langgraph.

A third name you may see is LangSmith: a separate web service from the same company for tracing and debugging runs. It is optional and not used in this video.

When to use which

The presenter's advice (07:16): when you want to go fast, ship a proof of concept, or build most everyday AI features, LangChain is a good choice, and many solid projects rely on it fully.

What you should see (in your head, no code yet): you can explain in one sentence what LangChain is, for example "a Python framework that wraps models, messages, tools and agents behind one simple interface, so I write less code and can switch providers easily". You also know that LangGraph is the engine underneath.

Common misunderstandings

  • "LangChain is a model." No. It contains no model. It calls a provider's model over the internet (or a local one through Ollama).
  • "LangChain is free, so the AI is free." The library is open source and free. The provider charges per token for each call, which is why you add credit to OpenAI in step 03.
  • "I only need langchain." You also need the integration package for your provider, for example langchain-openai. Forgetting it causes the first error in step 04.
  • Old tutorials. LangChain changed a lot before version 1.0. Code online with LLMChain, initialize_agent or from langchain.llms import … is older style. This guide uses LangChain 1.3.12 and its create_agent.
Recap
  • LangChain is a framework for building agents and LLM-powered applications; it simplifies AI development with an abstraction layer.
  • An LLM-powered app is more than input and output: it needs prompts, tools, memory and files around the model call. LangChain has a piece for each.
  • Compared with calling a provider directly, LangChain saves the most code on tools, the agent loop, memory, streaming and images, and lets you switch providers.
  • Providers run the models; each needs an integration package (langchain-openai for OpenAI) and an API key.
  • LangGraph is the lower-level engine; create_agent builds a LangGraph graph for you.
