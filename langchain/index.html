LangChain Crash Course: Agents, Tools & a Personal Chef

A beginner-friendly, step-by-step companion to the AI Career Lab crash course on LangChain 1.x in Python. You set up a project with uv, talk to a chat model, build agents that use tools and search the web with Tavily, give them short-term memory, send them images, and finish with an AI personal chef that looks at a photo of your ingredients and finds a recipe online. Every line of code is explained. The guide also fixes two bugs found in the repo and adds four extension steps and a 10-chapter handbook.

Compared with the GitHub repo

The chef project (steps 12–15) is embedded unchanged from Mohamad-Hachem/ACL_FastEat_Agent (commit ea320de, "creating our personal Agent"). Checking the repo and the video against each other turned up these differences and findings. Each one is explained on the page listed:

StepDifference or finding
04–11The lesson files are not in the repo, which contains only the chef project. They were transcribed from the video frames, checked against the transcript and run against the repo's locked versions. Each page says which frames it comes from.
04Temperature does nothing with gpt-5-nano. langchain-openai 1.3.4 drops any value other than 1 for GPT-5 reasoning models, and the video's temperature=1.0 is already the default. That's why the answers didn't get "more creative". The page explains temperature and suggests a model that supports it.
09, 14Unofficial tavily package. The video runs uv add tavily and the repo depends on tavily>=1.1.0. That PyPI package is published by an individual, not by Tavily. Tavily's official SDK is tavily-python, with the same import (from tavily import TavilyClient). Version 1.1.0 of tavily only calls Tavily's API, but the guide recommends the official package.
13dotenv instead of python-dotenv. The repo depends on dotenv, a deprecated shim whose only job is to install python-dotenv. It works; step 16 depends on python-dotenv directly.
13Bug: the chef never sees the request. photo_decoder.py sends {"type": "text", "text": "prompt"}, the word "prompt" in quotes instead of the prompt variable. It still works in the video because the system prompt says what to do. Fixed in step 16.
13Bug: missing space in prompt.py. The two halves of SYSTEM_CHEF_PROMPT are joined without a space, so the model reads "…in the photo.once you do that…". Fixed in step 16.
13The choose_image_file docstring mentions an image path "passed on the command line", but main.py never reads one. Step 16 adds it.
16–19Not in the video or the repo: extensions written for this guide and tested the same way.

How the code was verified

No real API keys were used. An offline test harness replaced the OpenAI chat model with a fake one that has the same LangChain interfaces, replaced Tavily's search with a canned result, and replaced the file picker. Every lesson file, the repo's chef project and every extension file then ran end to end against the repo's locked versions (langchain 1.3.12, langgraph 1.2.9, langchain-openai 1.3.4): 13 of 13 passed. This proves that the imports, APIs, message flow, tool calling, memory, streaming, structured output and image messages work with these versions. It does not prove what a real model will answer: the wording of answers shown in the guide comes from the video.

Before you start. You need an OpenAI API key with some credit (the presenter adds $5 on the billing page) and a free Tavily key (1,000 credits a month). Keep both in a .env file that is listed in .gitignore. Never paste a key into code or share it in a screenshot. The video briefly shows keys that the presenter says were deleted; this guide never reproduces them.
