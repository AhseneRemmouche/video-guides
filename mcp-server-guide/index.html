Build an MCP Server from Scratch

You build a small task-manager MCP server in Python: a SQLite database holds the tasks, a FastMCP server exposes three tools over it, and then three different clients use those tools — a plain FastMCP client, a LangChain agent, and Codex. It is written for complete beginners. What this guide adds beyond the video: every line of code is explained, and because there is no public repo, each snippet was transcribed from the video and then verified by running it locally against the exact library versions below.

About the code

There is no public code repository we could find for this project. The video never links one, and searching did not turn up an official source. So the code on every step page was transcribed from the video's on-screen editor frames, and then verified by running it locally against the exact library versions in the Stack above (fastmcp 4.1.6, langchain 1.4.9, langchain-openai 1.7.4, langgraph 1.2.20, python-dotenv 1.2.4, and the rest). Where the video shows a mistake or a flaky result, this guide reproduces it and explains the fix, rather than quietly tidying it up. In other words, what you copy here is not a guess from the captions — it is code that actually ran.
