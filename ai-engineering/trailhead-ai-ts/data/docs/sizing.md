# Frame size guide

Choose your frame size from your height:

| Height | Frame size |
|---|---|
| 155-165 cm | S |
| 165-175 cm | M |
| 175-185 cm | L |
| 185-195 cm | XL |

If you are between two sizes, choose the smaller size for a more agile ride or the larger size for more stability at speed.

You can exchange a bike for another size within 30 days, as long as it meets the return conditions.
